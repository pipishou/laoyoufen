# AI 审核官 · 判据提示词 v1.0

五个判据**各自独立调用**——绝不写成一个 prompt 连问五件事（会互相污染：模型看到"世界观"就往文学性上偏，看到"风险"就整体保守）。

统一输出契约（每个判据都必须返回 JSON，字段缺一即判该次调用失败，**不许默认放行**）：

```json
{"judge":"J1","score":4,"verdict":"pass","reason":"一句话，指到具体文字","span":"原文片段","confidence":0.8}
```

- `score` 1–5 整数；`verdict` ∈ `pass|fail|unsure`；`confidence` 0–1
- `span` 必须是原文的连续子串（用于人审定位；无法定位就写空字符串并在 reason 说明）
- 输出**只能**是这一个 JSON 对象，不要 markdown 围栏、不要解释

所有判据共用的上下文块：

```
【项目】广西老友粉店经营模拟器（浏览器游戏），时间跨度 3 年 36 个月，玩家经营一间街边粉店。
【红线】AI 不产数字（一切金额/百分比由确定性模拟给出，AI 只写文字）；不写政策文号、机构全称、真实人名；不仿写任何既有作品。
【对象】一条「街市事件」候选：标题 + 正文 + 2–3 个选项（选项各有短摘要与结算后一行结果）。
```

---

## J1 · 世界观（权重 0.30）

你是广西本地生活顾问。判断这条事件**是否发生在广西/南宁的现实土壤里**：气候（回南天、湿冷、台风季）、物产（酸笋、豆豉、山黄皮、米粉）、街巷形态（骑楼、巷口、夜市）、人的说话方式。

- 5：本地人看了会说"就是这样"
- 3：不违和，但换成任何南方城市都成立（缺本地锚点）
- 1：明显是外来想象（把广西写成东南亚、把米粉写成拉面、把酸笋写成酸菜）
- `fail` 条件：出现地理/物产硬错

## J2 · 工艺（权重 0.25）

你是做了二十年老友粉的老师傅。判断**工艺描述是否说得通**：汤是不是用豆豉酸笋爆香后下汤、粉是不是切粉/圆粉、酸笋发酵批次有没有前后矛盾、火候与出餐顺序对不对。

- 5：工艺细节经得起追问
- 3：大致合理，个别环节含混但不误导
- 1：工艺流程错（如"酸笋焯水去酸"＝把老友粉的根去掉）
- `fail` 条件：把关键工艺写反，玩家会学错

## J3 · 玩法可读（权重 0.25）

你是第一次打开这个游戏的玩家。判断**只看这条事件，你知不知道自己在选什么、每个选项大概会付出什么**：选项 label 是否动词化、summary 是否让人能预判代价、两个选项是否构成真取舍（而不是一个明显更优）。

- 5：一眼看懂，两个选项都心疼
- 3：能懂，但有一个选项是送分题
- 1：不知道在选什么，或选项同质
- `fail` 条件：无法判断后果，或选项实质相同

## J4 · 新颖（权重 0.20）

你是玩过大量经营游戏的评测者。判断这条事件在经营游戏品类里是否新鲜。

- 5：没见过，或见过但换了个很不一样的切法
- 4：同类里算有想法
- 3：常见套路，但处理得体
- 2：套路，且处理也一般
- 1：换皮复用，删掉也不损失什么

`fail` 条件：1 分（换皮复用）才 fail。**2 分不 fail，但会触发「J4≤2 强制人审」的地板**（`run_review.arbitrate` 硬判）。

> **v0.4「本地锚点密度」试验记录（结论：未采纳）**：曾把 J4 改成先数本地锚点个数（地理/物产/气候/语言四维）再给分，并配 J4≤2 地板。单次实测 pass_auto 只有 5（v0.3 同文本四次为 13/10/6/10），方向更差；另一次「骨架豁免+新料加分」措辞为 9（落在噪声带内）。
> 但该结论只有 **k=1**；同一份判据连跑 4 次，逐条裁决一致率仅 46.9%、pass_auto 标准差 2.49 —— **单 run 数据不足以判定两个版本谁更好**。故 J4 文本回滚 v0.3，仅保留地板（实测为无害守卫）。若再试锚点方案，必须 k≥3 多数票对照。

## J5 · 风险（否决闸，不参与加权）

你是内容合规与舆情审核。判断是否有：真实机构/政策指称、地域歧视或刻板印象、食品安全误导（把违规操作写成正面）、对真实人物的影射、可被截图断章取义的政治/民族表述。

- 5：干净
- 3：有轻微擦边，建议改词
- 1：必须改写
- `fail` 条件：任何一条红线命中；拿不准一律 `unsure`（进人审，不自行放行）

> **v0.3 起 J5 是闸不是分**：输出里 `score` 可留 `null`，只判 `pass/fail/unsure`。实测它对真人文案 100% 给 5，加权等于白送分；降闸之后才真正抓到「食药监抽查」「文旅局非遗」「市场监管所+地方标准」三条真人漏掉的合规风险。

## 仲裁（L2，确定性公式，不调模型）

**v0.3 版**（v0.1 的 J5 加权已被实测否决，见 `AI审核官-首轮校准-2026-11-08.md`）

```
J5 = 否决闸，不参与加权：fail → reject_auto；unsure/na → to_human
加权判据（na 的剔除后权重重新归一）：
J1 世界观 0.30 ｜ J2 工艺 0.25 ｜ J3 玩法可读 0.25 ｜ J4 新颖 0.20
S = Σ(w_k * s_k) / Σw_k
```

| 条件 | 裁决 |
|---|---|
| 任一判据调用失败/字段缺失 | `to_human`（失败方向永远是多找人看） |
| J1 或 J3 被标 na | `to_human` |
| J5 = fail | `reject_auto` |
| J5 = unsure | `to_human` |
| **J4 ≤ 2** | `to_human`（地板，先于总分判定；实测为无害守卫：命中条目 S 本来就在 2.7–3.4） |
| S ≥ 3.85 且 min(J1,J2) ≥ 3 且 无反 fail 且 极差 ≤ 2 | `pass_auto` → 进池（抽 5% 人审复核） |
| S ≤ 2.5 或 min(J1,J2) ≤ 1 或 任一 J 为 fail | `reject_auto` → 丢弃，留痕 |
| 其余（含任意 unsure） | `to_human` → 人审（唯一放行权） |

极差 = max(scores) − min(scores)，只算参与加权的判据。门槛 3.85 来自 32 条真人基准集的 S 分布（median 3.67 / p75 4.07）——**AI 文案要比现有真人文案的中位数更好才自动进池**。
