# B2 · 三层改造：机制层 / 目录协议层 / 最小角色集（推荐）

- 一句话：改造单位不是「skill」，是「层」——把 CCGS 当标准件仓库按层供货：L1 机制全搬（改写成我们的脚本）、L2 目录协议零成本落地（建目录 + 模板 + 命名规范）、L3 角色只留 3 个（其余 46 个是 3A 编制，丢弃）。
- 技法：类比迁移（技法 3）——把 CCGS 看成「五金店」而不是「现成家具」：拿标准件（螺丝、合页），不买整套柜子。
- 核心假设：CCGS 的可移植价值按层递减——机制层 ~90% 可移植、目录协议层 ~100%、角色层 ~10%（3/49）、skill 文本层 ~9%（改造后可用的约 7/74）。
- 支撑证据：
  - **L1 机制层可移植**：`story-done/SKILL.md`（351 行）里的四态 verdict（`COMPLETE / COMPLETE WITH NOTES / NOT ASSESSED / BLOCKED`，且「NOT ASSESSED 优先于两个通过」「必须点名什么能 settle」）、观察三证据（looking / asked / seen-on-screen，且「a described check is an assertion」）、证据过期检测（`stamp.txt` + `review-receipts.sh check` → `CHANGED:` / `GONE:` / `RECEIPT: NONE`）、`qa.level × Story Type` 豁免矩阵（「the look is never waived」）、scope 对照 `git status --porcelain`（OUT OF SCOPE）——**全是引擎无关的判据，5 条都能直接落进 `tools/reviewer`**。
  - **L2 目录协议层近零成本**：`design/registry/entities.yaml`（跨系统实体单一来源，`economy-designer.md:72-91` 明写「never define an item value that contradicts a registered entry without flagging it as a proposed registry change」）、`production/session-state/active.md`（会话断点，含 `Run result:` 行）、`production/qa/evidence/[slug]/[NN]-[what].png`（证据路径即命名规范）、`docs/tech-debt-register.md`、`docs/adoption-plan-[date].md`——建目录 + 抄 5 个模板，成本≈0。
  - **L3 角色层只要 3 个**：`economy-designer.md`（150 行：汇/漏建模、进度曲线必须写成带变量的公式并给区间两端算例、「sink 问题悬空就不是平衡」、经济健康度量按本项目数据算而非按品类均值）、`qa-lead`（证据裁量/四态判）、`performance-analyst`（帧预算/瓶颈定位，与我们已装的 `performance-optimization` 互补）。其余 46 个（narrative/world-builder/sound-designer/live-ops/community/accessibility/3 个引擎专精 ×N）对本项目无收益。
  - **断腿率实测**：68/74 skill 顶部内联 `yaml-helper.sh resolve_config`，25/74 调 `.claude/scripts/*`，32/74 含三引擎词——**7/74 ≈ 9% 才是「改一改能用」的部分**，其余是重写成本。
- 反证信号：三批做完后（① 机制落进脚本 ② 目录协议建好 ③ 3 个角色跑过一次），如果 `review_stats.py` 仍报不出「未执行/未评估」、或 `evidence/` 目录三个月零新增、或 economy-designer 输出的曲线没人用于调 `START_CASH=5000` 这类占位数——说明我们买的是一套「看起来专业」的流程，不是游戏，此时应回退到 B1 并停。
- 成本：P0 1.5 人时（机制层第一批：`ran` 第三态 + 四态 verdict 映射 + 观察三证据写进项目记忆）；P1 5 人时（眼睛绿：Playwright 四视口 + sha256 stamp + `CHANGED/GONE/NONE` 检查，接 `npm run gate:eye`）；P2 2 人时（3 个角色 brief 落到 `docs/agents/`，用 subagent 实跑一次汇/漏分析）。合计 **8.5 人时**，跨 3 个批次，可分批停。
- 可逆性：**双向**（每层独立开关）。L2 只是建目录与模板（删目录即回滚）；L1 是新脚本 `tools/gate/` 与 `review_log` 增字段（旧行不改、stats 兼容两态）；L3 只是 `docs/agents/*.md` 提示词，不参与运行时。
- 结论：**成立，推荐**。置信 HIGH（本地实测三层命中率 + CCGS 自证「standard 档 30 篇文档 / 58 分钟，双盲评排最后」＝文档不等于游戏）。
