# B2 · 类比迁移：把开罗的「解锁树 + 三道门」搬过来

**技法**：类比迁移——不抄具体物品，抄**机制形状**。开罗的节奏由三样东西咬合，不是由日历：

1. `rank.txt` 16 条奖励行（每行 1 个解锁物 + 若干`条件档`）：Max Moisture / More Shapes / More Soup Ingredients / More Toppings / **Ramen Hall Expansion** / **Ramen Hall Road Work** / **Buy Small–Amazing Shop** / More Line Tiles / More Investments…
   → 每一档都是「一个具体的新动词」，条件写在同一行里（例如扩建要 `8/4/4`、买店要 `9/4/3` 这类前置牌）。
2. `grade_review.txt` 11 级段位审查：费 5,000 → 2,000,000，条件列 4/7/10/15/20/24/30/34/40/50。**这是钱的主要去处**。
3. `region.txt` 7 区：解锁费 0 → 30,000，人口 500 → 30,000（第 7 区 65,535 = 不开放的哨兵）。
   → 区域解锁 = 买下一个客流池。

**形状总结**：**累计成就（trophy）→ 段位审查（付费门）→ 解锁新动词（rank）→ 用新动词买下更大的池子（region）**。四环相扣，任何一环卡住玩家都有明确的下一步。

**一句话**：节奏 = 「攒到 → 交钱过门 → 拿到新动词 → 用它开新池子」的循环。

段位审查（已有 `sim/grade.ts` 11 级）从「有层没门」升级成**唯一的跨阶门**，费用按本作经济重定：¥500 / 1,500 / 3,000 / 6,000 / 12,000 / 20,000 / 35,000 / 55,000 / 80,000 / 120,000（原表 ¥50–20,000 相对月营收 ¥27k 等于免费）。

**反证信号**：
- 若玩家在 S2 之后仍然「钱多到没处花」，说明资本梯度还是太浅 → 需检查「阶间价差是否 ≥ 3 倍」。
- 若解锁树变成「按提示点确定」，说明门槛太松（累计值离当前太近）。
- 若本土化只是换了物件名字、机制完全一样，则「照搬」退化成换皮 → 用 S3 的风格套 + AI 文案承担差异化。

**成本**：三批，约 3.5 天（S0 0.5 天 / 资本梯度 + 段位门 1.5 天 / 解锁表与 UI 1.5 天）。

**可逆性**：中高（解锁表是数据，门槛是常量；段位费可调；只有 S0 建店要动存档版本）。

**结论**：**成立，推荐**。它同时解掉三个已实测的病：钱没去处（B8 升级太便宜）、第 3 个月无决策（P24）、段位有层没门（P21/B6）。
