# 思考树：游戏节奏怎么对齐开罗拉面店（2026-11-14）

**根问题**：广西老友粉模拟器的「节奏」应该由什么驱动——日历、门槛，还是内容？

**用户口径（m04160）**：节奏照搬开罗：建店 → 第一碗老友粉 → 逐渐招人 → 店面布置 → 扩建；核心差异化只有三样（本土化 / AI / 前端 UI），其余照搬。

**成功判据**（可验证，不靠感觉）：
1. 每一阶段都有**一个新动词**（建、做、雇、装、扩、开），玩家第一次见到它时游戏界面里确实多了一个可点的东西。
2. 资本支出梯度**至少跨两个数量级**（装修 → 设备 → 扩建 → 新店），且总量级与「三年现金」同阶，钱必须有去处。
3. 第 3 个月起仍有决策（当前实测 M03–M35 营收恒定 ¥27.2k／流失 0%／无决策 = P24 未解）。

**早停条件**：若三支都无法让「第 3 个月有决策」与「钱有去处」同时成立，则先修经济梯度（B1 的前半段），节奏树留到下一轮。

## MECE 自检

- **互斥**：三支的驱动源不同——B1 挂日历、B2 挂门槛（奖励表 + 审查 + 区域）、B3 挂内容量。任一支成立即可单独解释节奏。
- **穷尽**：第四类「随机事件驱动节奏」不单列——事件是噪声（开罗 economy.txt 权重最高的三项是钱包/移动/进食 ±，属手感噪声），不能承担节奏骨架；已在 B3 里作为内容层吸收。
- **未展开池**（本轮不做）：多人/异步榜、季节限定菜、天气系统、员工心情剧情、AI 生成本地新闻。
