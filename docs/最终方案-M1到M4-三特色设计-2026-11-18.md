# 老友粉店 · 机制最终方案（M1–M4）· 2026-11-18

M1–M4 不是「补四块内容」，是**三条特色（本土化 / AI / 现代像素风）唯一的承载面**。
骨架取自开罗的成熟结构，**表达全部原创**——名字、台词、图标、数值一律从南宁生活里取，
不出现任何开罗专有名词。这是本方案的硬约束，不是建议。

---

## 0. 三句结论

1. **机制结构可以借，表达必须自己造**。版权保护的是表达（名字、台词、美术、具体数值表），不保护「对手店会抢客流」这种结构。所以：`enemy_store` 只用来**确认结构存在**，115 家店名与传闻一个都不抄；我们的 12 家同行、12 项街面、10 件家当、全部台词，都从南宁的巷子里长出来。
2. **三特色不是三个附加层，是每一条机制的三根轴**。同一个「同行抢客」的功能：本土化决定它是「隔壁巷子的老甘」而不是「Crooked Cafeteria」；AI 决定它每月说一句不一样的街坊话；像素风决定它在面板上是 48×48 的卷闸门小画。缺任一条，这个功能就退回成开罗的复制品。
3. **落地顺序不变，但每批的验收加了「三特色门」**：本土化门（渲染层零禁用词，`grep` 可机检）、AI 门（断网跑一遍不降级）、像素门（五视口截图 + 像素单位对齐）。三扇门都过才算交付。

- **只借结构**：抢份额、资金耗尽离场、街区投资换客群、第二货币买道具 —— 这些是**玩法结构**。

## 3. M1 · 同条街（2 天）

### 3.1 机制骨架（三段，照结构不照字）

| 开罗的机制 | 我们的做法 |
|---|---|
| 对手店会「抢走你的人气」 | 同区同行按 `fame` 分走客流池，份额上限 **35%**；你的菜单越好，被抢越少 |
| 资金耗尽 → 离场 → 你拿奖励 | 同行撑不下去 → 贴出「旺铺转让」→ **你可以折扣接手它那块铺面**（租金 −25%，需第 6 段） |
| 赚够了才走 → 你什么都拿不到 | 同行「做起来了」→ 变成**老对手**，份额固定、不再增长，但偶尔送你一句情报（下月哪个区会火） |
| —（我们的加项） | **服气**：赢它 3 次比赛 → 份额砍半、口碑互涨、每月送你一次食材（当次成本 −¥1） |

**为什么加「服气」**：老友粉店的竞争是「各做各的客」，赢家不会把邻居按死。这比「资金耗尽」更本土，也让玩家不必为了清净去刷比赛。

### 3.2 数据 `game/src/data/rivals.ts`


### 3.4 验收

- 无同行（或全服气）时，替身 36 月曲线与现在一致（回归锁）。
- 有同行时客流降 10–25%；赢一场比赛份额回升 ≥5 个点。
- 同行资金耗尽 → 「旺铺转让」出现在面板 → 接手后月租降 25%。
- 替身新增决策「去落场抢份额」，日志里能看到它至少参赛 3 次。

## 6. M4 · 落场（2–3 天）

### 6.1 轻量版先跑通手感（本批第一步）

- 报名后进 60 秒小局（游戏时间 1 小时，其余暂停）。
- 三个按钮：**支摊吆喝**（+分，冷却 3 秒）/ **端碗露一手**（+分 ×1.5，冷却 8 秒）/ **一锅端**（大分，整局 2 次）。
- 每次得分 = `基础分 × 该款在对应轴的分位 × (1 + 服务技能/200)`。
- 对手分按 `signature` 匀速涨，中途 1–2 次「对手爆发」（配一句战况台词）。
- 结算沿用现有名次与奖金表，另按名次给**人情**（照 M3）。

### 6.2 像素擂台

Phaser 场景（项目已装 3.90）：左右两条分数条、中间一锅冒蒸汽的像素汤锅、按钮按下时碗飞出去落在客人头上（不伤人，是夸张的漫画感）。命中粒子用 4 色。

### 6.3 验收

三命令的得分差异可测；「一锅端」整局限 2 次；打完名次与纯算分版一致（回归锁：同种子同结果）；像素场景在五视口不破版。

## 7. AI 接入：四条铁律

1. **只出文字，不出数字**。服务端 `sanitize_line()` 已有规则：含阿拉伯数字即回落本地模板。扩展到：长度 ≤ 28 字、不含禁用词、不含链接。
2. **每句都有本地备选**。AI 是「更好一点的版本」，不是必需品。断网 / 代理挂 / 超时 → 静默回落，玩家不该察觉。
3. **缓存键稳定**：`eventId:month:day`（已有 `ai_cache.jsonl`），同一句不重复请求；对手传闻按 `rival:month` 缓存。
4. **不碰机制名与数值**。AI 永远不知道「人情」「家当」这些词以外的系统细节，也就无法把数值编出来。

**四个 AI 落点（按风险从低到高）**：街区请求（M2，纯叙事）→ 同行传闻（M1）→ 转手买家的话（M3）→ 落场战况台词（M4）。店名候选（已有 `shop-names.ts`）留给 P2。

### 8.2 像素规则

- 所有间距、内边距、圆角取 **4px 网格**（现在有 3/5/7px 混用，逐步归一）。
- 边框统一 **2px**，用 `box-shadow` 做**切角**（像素角），不用 `border-radius`。
- 位图元素 `image-rendering: pixelated`。
- 字体：像素中文字体（Fusion Pixel / Ark Pixel 任选其一自托管），回落 `system-ui`；字号只用 12 / 14 / 16 / 20 四档。
- 图标：24×24，1px 描边 + 2 色，统一图集。

### 8.3 四处像素展示位（这是「现代像素风」真正被看见的地方）

1. **同行门面**（M1）：48×48，三档配色区分小摊 / 老店 / 名店。
2. **街区俯视图**（M2）：16×16 tile 的俯视小地图，花钱的地方长出图标。
3. **家当墙**（M3）：买下的物件真的挂在墙上，HUD 侧栏 3 格展示。
4. **落场擂台**（M4）：分数条 + 汤锅 + 飞碗粒子。

## 9. 排期与验收门

| 批次 | 工期 | 交付后玩家新动词 |
|---|---|---|
| P0 顺手清（含 §2.3 六处越界文案） | 半天 | 无（界面不再骗人，也不再露别人名字） |
| M1 同条街 | 2 天 | 「看这条街谁在跟我抢」「去落场把他打服」 |
| M2 街面 | 1.5 天 | 「花钱改这条街」「听街坊讲一句话」 |
| M3 人情 + 家当 | 1.5 天 | 「把卖不动的配方转手」「攒人情添件家当」 |
| M4 落场 | 2–3 天 | 「真的打一场」 |

**每批必过的四道门**

1. `npx tsc --noEmit` 0；`npx vitest run` 全过（当前 29 文件 283 用例）。
2. **本土化门**：`Select-String -Path game\src\ui\*.ts -Pattern 'Ramen|开罗|kairo'` 在渲染字符串里 **0 命中**。
3. **AI 门**：关掉代理（`LAOYOU_ALLOW_ORIGIN` 指向不存在端口即可）跑一遍，所有文案回落、无空白、console 0 error。
4. **像素门**：`python tools/gate/eye_gate.py shot --slug <批次>` 五视口 + 肉眼核对像素门面 / 小地图 / 家当墙。

**上线判断**：M1 + P0 发一版，然后请 bot 用同一脚本再跑一次试玩。看三件事——
① 「四个页签空」「评价归零」消失；② 报告里出现「这条街有人在抢我客」这类叙述；③ 玩家会不会主动点开「同条街」面板。前两条成立、第三条不成立 → 先补 HUD 上一条「同区份额」，别急着上 M2。

## 10. 不做什么

| 不搬 | 理由 |
|---|---|
| Ramen Hall（物理大厅、多店同场） | 我们已有分店，这套是开罗的物理空间概念，搬来成本高、收益低 |
| 抽奖（Lucky Draw） | 与「人情」的确定性回报冲突，也容易做成赌博感 |
| 四轴形容词命名 | 已用四实轴（做法 / 主料 / 粉型 / 加料）替代，更本土 |
| 开罗的数值表 | 单位不可换算，全部按「一碗毛利 × 月碗数」自己反推 |
| 开罗的任何名字、台词、图标 | 见 §2 |

**一句话**：骨架是别人的成熟结构，血肉必须是南宁的。三条特色里，本土化决定「像不像一家开在兴宁区的粉店」，AI 决定「这条街会不会自己说话」，像素风决定「玩家愿不愿意截图发出去」。
