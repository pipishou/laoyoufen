# 批 L′：店员成长（四属性 / 二十一项手艺 / 六门毕业技）（2026-11-24）

> 解 GAP 二轮的 P0-2「店员无属性与个人成长」。
> 开罗的店员是**会变强的**：`help「Staff 2」`原文「When a staff member's cooking skill
> increases, they will be able to **boil more noodles at once**. When service increases,
> they will be able to **carry more at once**」；本作此前的员工只有一个 1–5 的 `skill`，
> 雇来是什么样，走的时候还是什么样。

## 一、开罗原文对照（取证）

| 可取到的原文（`TheRamenSensei/取证/textassets/xls_out/`） | 本作 |
|---|---|
| `help「Staff 1」`：**Cooking**「stat 低于拉面难度就容易出错」/ **Service**「影响店员问出顾客偏好的速度」/ **Speed**「移动速度」 | 四属性：**火候 / 待客 / 脚力 / 耐磨** |
| `help「Staff 2」`：cooking 高了「一次能多煮几份」，service 高了「一次能多端几份」 | 火候 → 一锅多下份数（仍在原 `Math.min(2, …)` 封顶里） |
| `clerk_skill.txt` **21 行**（#0 調理の心得 / #3 麺のささやき / #5 小金の舞 / #7 頑強 / #19 努力家 …） | **21 项手艺**，同数量，按属性门槛自动学会 |
| `finishskill.txt` **11 行** + `help「Staff Finishing Skills」`「每位店员有一门收尾的本事，对应属性越高越有效」 | **6 门毕业技**（四属性都到 3 级才出），选能对上「收尾那一下」的六门 |
| `help「Staff 3」`：服务技能越高问出偏好越快 | 待客 → `surveyRate` 加上去 |

第四项**耐磨**不是新造：`clerk_skill #7 頑強`「体力が減りづらくなる」、`#19 努力家`
「店員の経験値アップ」在开罗是两条独立技能，本作把它合成一条属性，落在「累得慢 / 不轻易走 / 学得快」。

## 二、怎么长

- **只存一个数**：`StaffMember.xp`。四属性、学会的手艺、毕业技**全部现算**（`sim/staff-grow.ts`）。
  为什么：存下来就会出现「xp 涨了但属性没跟上」这类脏状态，老档迁移也更容易出岔。
- 每天收市，在岗的人 `+1`（学过「早起」「手上不停」的更多，封顶 +3）；**累到 60 以上只算半格** ——
  硬撑着的人学不进东西，这一句是本批唯一的惩罚。今天休息的人不算。
- 升一级给 1 点属性：主项（煮粉→火候、备料→耐磨、跑堂→待客）与其余三项交替派发，各自封顶 8。
- 十二级封顶（`XP_STEPS = [3,8,15,24,35,48,63,80,99,120,143,168]`），派满正好主项 7、其余各 3 ——
  毕业技（四属性 3 级）大约在一个人干满 168 天时到手。

## 七、新缺口

- **P311**：成长让员工更耐用，替身因此少换人、少腾出现金去扩建，营收 −6.9%。要不要给它一条
  「雇满 2 人后钩子转向扩建」的引导，得先看真人局里是不是也这样。
- **P312**：四属性在界面上只有一行字，没有「这个人擅长什么、还差什么」的高低对比，玩家难比较两个人。
- **P313**：手艺按属性自动学，玩家没有选择权；开罗是可以分配练哪条的（`clerk_skill` 有 tier 权重）。
- **P314**：`XP_STEPS` 十二级与四属性阈值是两个独立表，改一个就得重算另一个（与 P310 同类）。
- **P315**：毕业技六门里「话不多」「碗边擦净」的效果偏弱，实际只有「多下一份」被感觉得到。
