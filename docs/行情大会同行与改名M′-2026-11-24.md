## 四、同行 8 → 16（`game/src/data/rivals.ts`）

新增八家落在原来空着的区：西乡塘两家（石埠路口、安吉客运站）、邕宁（蒲庙老街）、武鸣（城厢）、隆安（县城）、横州、马山、宾阳。
每家仍是「招牌一款 + 第二款 + 三句街坊话 + 名气 + 接手价 + 服气门槛」，招牌名与价位照真南宁的写法（生榨米粉 ¥8、柠檬鸭粉 ¥13、八角卤粉 ¥7、猪脚粉 ¥14、茉莉花茶粉 ¥11）。

### 比价公式改了（R-5）

原来：

```ts
sum += (r.gap * 0.02 * weight) / rows.length;
const mult = 1 - sum;
```

家数从 8 涨到 16 之后，这条会把每家的影响摊成一半 —— 街上换掉一半店，乘数几乎不动。改成两层：

```ts
// 全街均价占七成、最近三家（比你便宜最多的三家）占三成
const mult = 1 - (avg * 0.7 + nearAvg * 0.3) * 0.02;
```

上限仍是 `PRICE_WAR_CAP`（两边夹住），收益侧 `1 + CAP / 2` 不变。

## 五、菜单改名（对应开罗 `ramen_name`）

- `GameState.menuAlias?: Record<string, string>`，键是菜单款的 `item.id`（**不是 index** —— 删一款、换顺序，名字不能跟着乱）；可选字段，**不升存档版本**（仍 37）。
- `game/src/sim/dish.ts` 的 `dishNameOfItem()` 先读别名，再退回系统名；
- `renameDish(state, itemId, raw)`：去首尾空格与换行、去掉 `<>`、最多 `DISH_ALIAS_MAX = 8` 字；**留空就是改回系统名**，别名那条会被删掉（存档里不留空字符串）。
- 界面：菜单卡片里一行小输入框（`[data-rename]`），监听 `change` 而不是 `input` —— 每敲一个字就重渲染会把光标吞掉。
- 不检查重名：街边店真会有人把两款都叫「老友粉」，客人自己会认价牌。

## 七、新缺口

- **P316**：同行翻倍 + 行情翻倍让替身营收 −6.5%，说明「街面变热闹」的世界成本落在玩家身上；要不要给「同行多 = 客流池也大」一点补偿，得看下一轮试玩。
- **P317**：十六家里有八家的区在第二圈以外，第一圈玩家看不到 —— 现在的对手表是按区筛的，远处的家只贡献人气数字，不参与比价，这个不对称没在界面里说明。
- **P318**：改名只有菜单卡片一处入口，改名的结果不会进打烊单、不进 AI 台词（AI 目前念的还是 `dishNameOfItem`，会跟着改名走，但 `menu_advice` 的缓存键没带名字，改名之后旧句可能还在）。
- **P319**：五级赛事 5 / 5 / 5 / 5 / 4 仍然不是整除，全国级少一场；再补一场「全国·老友粉产业大会」就能对齐。
- **P320**：行情十六条里「停水」「气价」是纯减益，没有任何对冲手段；十六分之一的日子玩家只能挨着。
