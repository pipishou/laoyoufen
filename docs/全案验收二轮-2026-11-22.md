## 四、CCGS 三条游戏性判据

按 `claude game studio` 的核心框架（core loop / progression / feedback），逐条对照本作：

### 4.1 Core loop：一局之内是否闭合、是否可读

一个营业日内：**备料（配方页定价、进货、练手）→ 开门（客流、排队、出碗）→ 打烊（单子、报纸、钩子）**。
- 出碗是一个**单出口**（`stationServeFactor` → `serveCooldown`），玩家看到的「一碗几分」与实际冷却同源；
- 三个走人出口（队满 / 看价牌 / 等不及）各自记账（`lostQueue/lostPrice/lostWait`），打烊单与红标都指向主因；
- 九档四维与九档评语只在高/低档开口，中间不说话 —— **不说废话是这一层最重要的一条**。

判据：**闭合 ✓**。一天之内玩家能改变的四件事（价、料、手、店面）都在当天结算里显形。

### 4.2 Progression：长线是否有层次、是否有代价

七条长线，代价各不相同，互不替代：

| 线 | 代价 | 上限 |
|---|---|---|
| 段位（11 级） | ¥82,600 + 人次 | 解锁菜单款数与地图 |
| 店面（6 套） | ¥15,800 | 进店/耐心/满意 |
| 碗（5 只） | ¥700 | 出碗/料钱/耐心 |
| 家当（12 件 + 8 组搭配） | ¥9,780 | 六条出口 |
| 设备（四件 × 4 档） | ¥44,300 | 三段并行 |
| 进货档（3 档） | 每碗料钱 ×1–2.6 | 相与料钱 |
| 手上的功夫（36 节点） | 人情 + ¥1,300/支 | 五条出口，统一夹顶 |

判据：**有层次 ✓**，且每条线都有自己的货币（钱 / 人情 / 口碑 / 人次），不出现「一种资源通吃」。

### 4.3 Feedback：每个动作是否都有回声

- 数值回声：九档格、三段行、进货抬头、技法小方块、比价一句、行情一行；
- 人的回声：15 个 AI 落点，每个落点只在**有该说的事**时开口（低档/高档、钩子、行情、评定、闲话）；
- 票据回声：打烊单（主句 + why + 日注）、街坊报 5 条、图鉴七段（味道/碗/地图/报纸/技法）。

判据：**有回声 ✓**，但有两处仍薄：练满技法外面没人知道（P188）、进货档不进打烊单（P184）。

## 七、下一步建议（按性价比排序）

1. **热卖点火稳定性**（P171）：现在它主导 36 月方差，任何经济改动的信噪比都被它吃掉；
2. **练满的外部回声**（P188 / P184）：already 有账本与报纸两张票据，接上去很便宜；
3. **技法支间的依赖**（P187）：一招锁一招，长线立刻就厚起来；
4. **同行价浮动**（P153 后续）：让比价从「一次定价」变成「一周拉锯」；
5. **开店成本与现金去处**（P173）：段位费降下来之后，后期钱太多没有出口。
