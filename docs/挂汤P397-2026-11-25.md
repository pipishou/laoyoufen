## 三、为什么不做成属性（地图 B 的 C 方案）

- 四维九档是「一碗粉好在哪」的四个解释：味道、浇头、出碗、人情。加第五维要把
  `tier.test.ts` 的三十七句验收、`score.ts` 的封顶、九档文案全部重写；
- 胶质在现实里**不是另一种味道**，是口感的厚度 —— 它本来就该落在「客人怎么夸」上；
- 一句「今天有几位客人说汤挂在粉上」，比一个 +2 的数字更像南宁的店。

## 五、这一批留下的缺口

- **P404**：`thick` 只记「几碗」，不记「谁说的」—— 街坊那句口感与当天真实的人对不上时，玩家也没法核；
- **P405**：`broth_thick_voice` 的上下文写死 `{ 汤: "挂得住", 嘴: "黏" }`，换了底也这么说；
- **P406**：打烊单已经七行（功课 / 为什么 / 菜单 / 到点 / 挂汤），375 宽要滑两屏；
- **P407**：`soupPipelineWords()` 仍只在配方页出现，打烊单与 AI 都不提工序（P401 未解）。
