## 四、出口纪律（为什么只有这两个）

`capacityOf` 已经叠了「设备 + 门路 + 杂货 − 零售」，`stageMinutes` 叠了「设备 + 门路最慢段」，
`spawnChance` 叠了「口碑 / 段位 / 家当 / 店的样子 / 人情 / 区能量 / 热卖 / 行情 / 比价 / 技法」。
再加一层乘数就是第六层（P154 的上限从没验证过）。所以成套度只给：

1. **座位 +1，一次性**（记 `flow.slotSeatPrize`，永不重复）；
2. **进店 +4%，相加**（`slotAttractMult` 返回 `1 + 0.04`，不是连乘）。

两个都不动料钱、不动出碗分钟数。

原因不是杂货（替身不花人情），而是**成套度那一条**：替身照着钩子买矮凳、买桌，座位到 6 时

也就是说：这一条奖励虽小，落在**最紧的那个出口**上，于是被放大。记 **P301**。

## 七、新缺口

- **P301**：成套「座位 +1」免费送在瓶颈口上，替身营收 +21.6%；下一步要么改成「按已用座位比例算一次小额」，

- **P305**：`invest.test.ts` 与 `goods.test.ts` 的价格区间断言是「表级」的，每加条目都会再撞一次；
  该改成「按类别各取一条」的判据。

## 九、与开罗对照（这一批）
