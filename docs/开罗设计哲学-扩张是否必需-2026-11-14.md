# 开罗的扩张是不是必需的？—— 老友粉店的「做得好也能活」路线

- 日期：2026-11-14
- 取证：`D:\项目\REA\REA\逆向\_逆向上游\TheRamenSensei\取证\textassets\xls_out\English.lproj__*.txt`（39 张表，[COMPUTED]）
- 结论等级：扩张「非必需」= **HIGH**（表直接可读）；「味道换溢价」的量级 = **MED**（需实跑校准）

## 一、三句结论

1. **开罗里扩张是升级奖励，不是通关条件。** `rank.txt` 把「扩地／修路／买店／加拉面线／多投资」全部列在 rank 奖励表，条件写成等级阈值；不做也能继续经营，只是少了这些选项。
2. **它真正的成长引擎是 45 条拉面技能**（`ramen_skill.txt`），其中三条直接绕开座位产能提升营收：Charisma「顾客来访率 +X%」、Rarity「拉面售价 +X%」、Elegant「材料成本 −X%」。**做好面 = 来人更多 + 卖得更贵 + 成本更低**，三条都不需要多加一个座位。
3. **固定支出只有店租与店员月给，没有随规模上涨的强制成本。** 小店月租 5,000（`store_data.txt` 列 21），主店 Lv1 的人气/魅力可从 50/20 长到 Lv4 的 420/150 —— **不换店，靠等级也能变强**。

## 四、`rank.txt`：扩张是奖励项

| rank 行 | 奖励 | 解锁条件（等级阈值示例） |
|---|---|---|
| 9 | Ramen Hall Expansion（扩地） | 8 / 13 / 17 / 23 / 27 / 34 / 42 / 49 |
| 10 | Road Work（修路） | 4 / 9 / 14 / 26 / 35 |

→ 「买更大店面」和「多一条拉面线」是**同一张奖励表里的两行**，和「多一种粉型」「汤料上限 +1」平级。玩家的选择是「这一级奖励我拿地还是拿产能还是拿配方」。

## 五、`grade_review.txt`：段位要的是钱与经营指标，不是面积

11 级：评定费 5,000 → 2,000,000，条件列 4/7/10/15/20/24/30/34/40/50，末级 Secret Grading 额外要求 7,000 与 56（对应 trophy 里的「常客 56 / 段位 50」一档）。

→ **段位门槛全部是累计经营量，没有任何一项写「店面必须 ≥ X」**。小店只要活得久、卖得多，照样能评到顶级。

## 六、我们偏在哪

现在的实现把「产能」当主成长轴：座位／灶台／`capacity`；味道只走一条慢通道
`score.total → 满意度 → 口碑 → repFactor → spawnChance`（`game/src/sim/customer.ts:139`、`:169`）。

缺的正是开罗那两条直连：

| 开罗机制 | 我们现状 | 后果 |
|---|---|---|
| Charisma：味道好→来访率 | 味道只经口碑间接影响，`repFactor` 上限 1.0× | 做好面来人不够快 |
| Rarity：味道好→卖得贵 | 价格只由玩家定，`priceFit` 单向惩罚（`customer.ts:171`） | 味道 100 和味道 60 卖同一个价 |
| Elegant：味道好→成本低 | 无 | 精品路线没有毛利回报 |

**所以「做得好也能活」在现模型里不成立**——4 座不操作局期末现金 −10,508（账本行 19）就是证据。

## 七、改法（最小、可测）—— 已实施

1. `spawnChance` 增味道因子：`0.7 + score.total/100 × 0.6`（味道 0→0.7×，50→1.0×，100→1.3×）。
2. 新增 `priceTolerance(total)`：味道 ≤55 = 1.0，味道 100 = 1.25（开罗 Rarity 的位置）。
3. **顾客看价牌**：`tickCustomers` 里若 `state.price > arch.budget × priceTolerance(total)` → 掉头走，计流失并写 `flow.lastLostReason`。涨价不再是白捡的钱。
4. **修基础成本**：`BASE_COST` 原为「全部汤料＋全部粉料加总」≈¥6.3，等于每碗放了所有料；改为 `GUANGXI.bowlCostYuan`＝¥4.2（`docs/数值来源与换算-2026-11-12.md` 口径）。
