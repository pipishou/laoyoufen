# 技法校准（批次十一）· 2026-11-22

## 一、解决什么

批次六做的十二支技法树是「平铺」的：三十六格并排，谁先练谁后练只看人情够不够。开罗 `ramen_skill.txt` 45 行其实是**树** —— 后一支先要前一支。平铺的后果很具体：玩家一上来就把四门里最划算的几支点满，中间那些「不好不坏」的支永远不点，三十六格里有一半是摆设。

这一批做两件事：

1. **同门前置**：四条支要先有同门的一支（一级即可），给树一点形状。
2. **外部回声**：练满一支会在街坊报上留一行（批次九的报纸第一次为「手上的功夫」说话）。

## 二、前置怎么挂

`game/src/data/skill.ts` 的 `SkillBranch` 加了 `prev?: string`，四条支挂上：

| 支 | 门槛 | 理由 |
|---|---|---|
| 爆香 `sear` | 先有 看火 `wok_fire` | 火不稳就谈镬气，是无源之水 |
| 笋丝 `sour_cut` | 先有 切片 `slice` | 刀不稳切不出匀丝 |
| 记脸 `memory` | 先有 招呼 `greet` | 不招呼人，记脸没处记 |
| 排队 `queue` | 先有 记账 `ledger` | 排队是账上的事，不是灶上的事 |

`game/src/sim/skill.ts` 的 `learnSkill` 在查表之后、查人情之前判前置，失败给一句人话：`先练「看火」`。**不消耗任何人情** —— 前置没满足时连点都不算。

剩下八支仍是「一门里头一支」，随时能练；一共两种门槛，不做三级链（三级链会让前 36 小时只能练一条线）。

## 五、没做的两件（写清楚，不装作做了）

1. **夜间排期（一夜一件事）**：方案里想的是每晚只能做一件事（练技法 / 补货 / 早睡），把人情、钱、时间三样真正绑在一起。这一批没做 —— 它要动 `endDay` 的时序，而 `endDay` 现在已经有打烊单、报纸、账本、袋装、零售五个出口，插队要先重排一遍，风险大于收益。记 **P226**。
2. **`SKILL_CAP` 的三局面 × 四种子实测**：替身不练技法（它按固定菜单卖碗），要测「全满 vs 零技法」得给替身加一个开关。这一批只在测试里验了「全练满时五条出口确实撞到 CAP」，没有跑真局面。记 **P227**，并说明现状：`SKILL_CAP = { servePct: .15, costPct: .12, patiencePct: .15, satBonus: 4, attractPct: .12 }` 仍是拍的数。
