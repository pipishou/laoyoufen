# M4 落场：六十秒的小局，按 1/2/3 出招

> 2026-11-18 · 对应 `docs/最终方案-M1到M4-三特色设计-2026-11-18.md` 的 M4 · 代码 `game/src/data/arena.ts` / `game/src/sim/arena.ts` / `game/src/ui/arena.ts`

## 0. 三句话

1. 照开罗的 `Ramen Arena` 做了三块场地（菜市口早场 / 邕江边夜摊 / 老友擂台），每块只看四样里的不同权重；六十秒一局，按 **1 支摊吆喝 / 2 端碗露一手 / 3 一锅端** 出招，分高的赢。
2. 一天只有一场，第二场要 6 点人情，第三场不让上 —— 把 P56「人情攒满没处花」接上了一个出口。
3. 落场期间**店里的钟停住**（`tickMinute` 直接返回 false）：60 秒是真实时间，不该同时跑营业分钟。

## 2. 三块场地

| 场地 | 门槛 | 四轴权重（味/香/量/魅力） | 对手基准 | 奖金 | 一句话 |
| --- | --- | --- | --- | --- | --- |
| 菜市口早场 `market` | 0 段 | 0.40 / 0.15 / 0.30 / 0.15 | 633 | ¥800 | 菜市口就认一个「够不够饱」，二两在这里不顶事。 |
| 邕江边夜摊 `river` | 3 段 | 0.25 / 0.40 / 0.10 / 0.25 | 728 | ¥1,500 | 江边这摊子不看份量，看你这锅炒得香不香。 |
| 老友擂台 `ring` | 6 段 | 0.30 / 0.20 / 0.20 / 0.30 | 855 | ¥3,500 | 上擂台不讲情面，四样少一样都被人拿住。 |

（对手基准是默认配方 + 兴宁「老甘饮食店」（实力 62）算出来的；配方越好、口碑越高，对面也跟着水涨船高。）

## 3. 三条命令

| 键 | 命令 | 冷却 | 底分 | 看哪一轴 | 开罗对应 |
| --- | --- | --- | --- | --- | --- |
| 1 | 支摊吆喝 | 2.2 s | 14 | 魅力 | `Pop Up: Raise popularity` |
| 2 | 端碗露一手 | 3.4 s | 16 | 味道 | `Charisma Up` |
| 3 | 一锅端 | 9.0 s | 30 | 香气 | `Spirit Bowl` |

单次得分 = `底分 × max(0.35, 那一轴/60) × (1 + 服务技能/200) × (0.85 + 这碗粉在本场的基础值/400)`。
所以：**三招全按满**在菜市口能赢默认配置，在擂台必须先把味道/香气/份量/口碑都提上去 —— 跟开罗「擂台四样都要齐」一致。

## 4. 三个接线点

- `game/src/sim/state.ts` 的 `tickMinute()` 开头 `if (state.arena) return false;` —— 落场时店里的营业分钟不走。
- `game/src/sim/arena.ts` 的 `startArena()` / `arenaOpen()` —— 场地门槛、一天一场、第二场扣 6 点人情、第三场拒绝；`arenaRunsToday()` 用 `arenaDay === month*100 + day` 判「今天」。
- `game/src/ui/panels.ts` 的 `contestHtml()` —— 比赛页新增「落场 · …」段，三张卡：场地名 / 这碗粉值多少 / 对手与预计分 / 上场按钮（不可上时按钮 disabled 且写明理由）。

## 5. 数值平衡（本轮踩过的坑）

第一版 `RIVAL_RATE_PER_SEC = 12.5`，玩家把三招全按满只有约 641 分，而菜市口对手要 817 分 —— **最难的场地都打不过，最简单的也打不过**，测试直接照出来（`一直出大招就能赢，光站着就输` 失败）。调整：

- `RIVAL_RATE_PER_SEC` 12.5 → **9.5**（对手从 817 降到 633）；
- `holler.base` 12 → **14**（保底那招不再是废招）；
- `ARENA_RETRY_MAX` 2 → **1**（原来说「一天两回」但实际能打三场，文案与逻辑对不上，测试抓出来的）。

调后：满按三招 ≈ 900 分，菜市口能赢；擂台仍要 870 分以上，得靠更好的配方与服务技能。

## 8. 缺口与复现

缺口（已进账本）：

- **P58**：擂台上两个方块只是横向位移，没有出招动作帧；三招的手感只能靠按钮冷却与日志。
- **P59**：对手只有「本区最强同行」一个，没做成开罗那种按场地/段位的对手池。
- **P60**：落场结果不影响 M1 同条街的份额（赢了不额外抢客），两套系统还没咬合。

复现：

```powershell
cd game; npx tsc --noEmit; npx vitest run; npm run build
cd ..; python tools/gate/copy_gate.py
cd game; npx vite preview --port 4187 --strictPort --host 127.0.0.1   # 另开一个窗口

```
