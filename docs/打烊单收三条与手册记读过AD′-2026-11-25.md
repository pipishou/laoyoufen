# 打烊单收三条 · 手册记读过（批 AD′）· 2026-11-25

> 两条都是「内容没变，读起来变了」的小事：打烊单不再一屏滑两页，手册翻过的页留个印。
> 一格数值都没动。

---

## 一、打烊单折行（解 P406）

**问题**：到批 AB′ 为止，打烊单底部已经有五句可以说：功课（前三十天十二幕）/ 为什么（掉人）/
菜单（哪款不动）/ 到点（门路走完）/ 挂汤（猪脚卤水）。五句全有内容时，
375 宽要滑两屏才看完 —— 而打烊单是「一天结束看一次」的东西，滑两屏就等于没人看。

**做法**：有内容的那几行按顺序排好，**超过三条就收起来**，末尾留一行红字
「还有 N 条 · 点开」；点开变「收起」。三条是量出来的：375 宽一屏正好放进三条十一号字。

- `game/src/ui/hud.ts`：`.daywhy` 末尾加 `<span data-why-fold></span>`，新增 `foldWhyLines()`
  与 `whyOpen` 开关（点一下就地重排，不重新渲染整张单）；
- `game/src/ui/hud.css`：`[data-why-fold]` 红色点线小字，空的时候不占位。

**纪律**：只收起、不删句、不改顺序 —— 收起来的三句点一下就都在，不玩「重要的藏起来」。

## 二、手册读过标记（解 P387）

**问题**：十六页手册默认全收起，翻过哪几页、还有几页没翻，全凭记性。

**做法**：展开即算读过（`<details>` 的 `toggle` 事件），页签上写一个「读过」，
抬头写「N / 十六 读过」，读过的页标题收一档（`opacity:.72`）。

- `game/src/sim/manual.ts`（新）：`manualRead` / `manualHasRead` / `markManualRead` /
  `manualReadCount` / `manualReadWords`（「还没翻过」/「翻过五页，还剩十一页」/「全翻过了」）；
- `game/src/sim/state.ts`：`GameState.manual?: { read: string[] }`（可选，**存档仍 37**）；
- `game/src/ui/panels.ts`：`details` 上挂 `data-read="1"` 与 `.mread`「读过」；
  `wrap` 上挂 `toggle` 捕获监听 → `actions.readManual(id)`；缓存键补 `manualRead(s).length`
  （**第十三次「键漏字段」**：不加这格，标记写进状态了、界面还是旧的）；
- `game/src/main.ts`：`readManual(id)` 动作，成功才 `refresh()`；
- `game/src/ui/hud.css`：`.mpage[data-read="1"] > summary` 收一档、`.mread` 木色小牌。

**纪律**：只记读没读，**不给任何奖励**（手册是说明书，不是收集品）；空 id 不记；
老档没有这个字段就当一页没读。

## 四、探针踩到的两件事

1. **`.daywhy span` 会把折叠按钮自己也数进去** —— 第一版断言「可见三条」拿到 4，
   要写成 `span:not([data-why-fold])`；
2. **日结里的台词不是塞字段就出得来的**：`为什么` 那行读 `dayReport.lostQueue/lostPrice/lostWait`
   （`game/src/sim/bottleneck.ts:178`），`功课` 那行读 `state.flow.actToday` 而不是 `dayReport.act`。
   探针要摆的是这两处真入口，不是编一句文本。

## 五、留下的缺口

- **P411**：折叠阈值写死三条，窄屏更窄（320）时其实两条就够；
- **P412**：收起来的三句没有「点开过」的记忆，每天打烊都要再点一次；
- **P413**：手册「读过」只在图鉴页，设置弹窗那份操作一览不算；
- **P414**：`manualReadWords` 目前只有测试在调，界面上还没用上（抬头写的是 `N / 16 读过`）。
