## 二、AI 能力

### 判据

1. **只说人话，不报数字**：服务端 `LINE_RULES` 有 `CN_QUANTITY` 红线，带数量词的整句直接丢掉；场景提示词逐条写明「不报价钱、不提数值、不提加成、不劝接着买」。
2. **每句都有本地兜底**：`LOCAL` 每个 kind 四句，断网/接口挂了照样有人说话。
3. **有预算与配额**：`LINE_BUDGET = 330`，`guest_talk` 配额 40，防「一天问到底」把额度烧光。
4. **落点覆盖玩家的每个动作**：买设备、买门路、买杂货、点手艺、店员长进、成套凑齐、行情配对、店员劝留、菜单改名。

### 现状

- 落点 **28 个**（`game/src/ai/lines.ts` 的 `LineKind`），`tools/gate/audit_ai.py` 线上 **28 / 28 remote** 全 OK。
- 服务端场景提示词 **28 条**（`server/app.py` 的 `LINE_SCENES`），每条三到四条禁令。
- 事件表与服务端对齐：`server/events.json` 从游戏重导出 **83 条**（`550e03c` 修掉的 P344：两边会走散）。

## 三、前端现代像素风

### 判据（`python -X utf8 tools/gate/audit_pixel.py`）

| 项 | 要求 | 实测 |
| --- | --- | --- |
| 字面色值 | 0 处（只许 `:root` 的 token 与 `rgba` 阴影） | **0** |
| 色板 | `hud.css :root` 12 个 token | 12（ink / ink2 / wood / sand / cream / paper2 / paper / red / orange / green / gold / blue） |
| 图标 | 像素拼块图集 | **21** 条（本轮加了 bean / tea / lamp / chalk / pencil） |
| 字体 | 像素 woff2 随包 | `@font-face` true + woff2 引用 true |
| 采样 | `image-rendering: pixelated` | 1 |
| 动效 | 只用 `steps()` 硬切帧 | `@keyframes` 14 条 / `steps(` 8 处 / `prefers-reduced-motion` 2 处 |
| 面板 | 段数、图标调用、动作种类 | `sechd` **58** 段 / `icon(` **54** 处 / `data-act` **45** 种 |
| 五视口 | 375 · 667 · 390 · 768 · 1440 都不白屏、不叠字 | `eye_gate --slug shopname` **723 · 778 · 584 · 1247 · 1506** 色，stamp **168** |

### 像素风的三条纪律（本轮都在守）

1. **不加半像素**：招牌、技艺格子、成套金勾、虚线推荐都用 2px 边框 + 硬阴影，不用圆角与渐变。
2. **动效尊重系统设置**：`prefers-reduced-motion` 覆盖（点树 / 打烊单 / toast）。
3. **红只留给「现在最缺」**：Q′ 把推荐虚线从红改成木色（`var(--wood)`）—— 红是「这一项挡住了今天的生意」，不能被推荐用掉。

### 还没做到的

- **P382** 木色虚线在 375 宽只剩 1px，不够「像像素」。
- **P387** 十六页手册没有「读没读过」的标记，仍是平面清单。
