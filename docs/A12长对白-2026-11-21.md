# A12 长对白：点一下客人，他说一句 —— 2026-11-21

## 三句话

1. 开罗 `talk.txt` 有 244 行顾客台词，我们不做 244 句，做**六种场面各四句长对白**（24 句），因为玩家点开一个人，是想听人说话，不是想看数值。
2. 场面由**处境**决定，不由随机决定：还在等 / 吃满意了 / 吃完不咸不淡 / 吃出问题 / 常客 / 送过东西的。
3. 这一批真正修的是一个**看不见的交互 bug**：HUD 整体 `pointer-events: none`，客人行原本点不到，鼠标点下去被画布吃掉。

## 六种场面

| 场面 | 什么时候用 | 句子在说什么 |
| --- | --- | --- |
| `queue` 还在等 | 顾客 `status === "waiting"` | 抱怨时间、顺手点评你的灶小 |
| `praise` 吃完了，还满意 | 口碑 ≥ 3.8 且没让他久等 | 夸具体某一处（酸笋、汤、粉身），不说「好吃」两个字 |
| `plain` 吃完了 | 上面都不满足 | 说说明天还来不来的实话 |
| `complain` 吃完了，不太满意 | `waited > 4`（久等） | 委婉挑刺，并自己给台阶 |
| `regular` 常来的街坊 | `regular === true` | 报自家口味、聊孩子、说「你唔好执笠」 |
| `gift` 送过东西的客人 | 留给送礼链（本轮未接） | 谢一句、给点自家腌的东西 |

句子都写成南宁人说话的样子：「唔急唔急，我睇你一个人又煮又收钱」「我阿妈话你人实在，叫我带啲嘢过嚟」。**选句用哈希**（`playerId:archetypeId:客户id:month:day`），同一局读档回来，同一个人说的还是同一句，而且不消耗 `state.rng` —— 说话不该影响出货。

## 一处真 bug：客人行点不到

第一版探针点不下去，报的是：

```
<canvas width="512" height="384"> from <div id="game">…</div> subtree intercepts pointer events
```

原因在 `game/src/ui/hud.css`：

```css
#hud { position: absolute; inset: 0; pointer-events: none; }
```

HUD 整体是穿透的（否则会挡住画布上的灶台交互），只有 `#tray` / `#bottombar` / `button.pill` 自己把事件接回来。`.custlist` 在 `.panel` 里，天然点不到 —— **如果不做真点探针，这个功能上线后玩家一次都不会触发**。

修法：

```css
.custlist { pointer-events: auto; }
.custlist .cust[data-uid] { cursor: pointer; }
.custlist .cust[data-uid]:hover { background: var(--paper2); }
```

## 两个坑

1. **探针的稳定性检查会被 tick 打断**：`page.click()` 要等元素「stable」，而顾客行每帧都可能被重绘 → 一直等到元素被替换掉。处置：命中测试用 `getComputedStyle(...).pointerEvents === "auto"` 断言，点击本身用 `dispatchEvent(new MouseEvent('click', { bubbles: true }))`。
2. **成就 toast 会抢掉对白的 toast**：注入 4.2 口碑会立刻触发「口碑 4.0」成就，把刚弹出的对白顶掉 → 探针里注入 `pendingTrophies = []` 并清空 `#toasts`。
