# 批次四：段位只降费，评语交给评委说

> 依据 `docs/下一轮开发方案-2026-11-21.md` 的批次四。
> 开罗对应：`grade_review.txt` 十一级（费用 5,000 → 5,000,000 KCU，合计 8,330,000 ≈ **8,330 碗**；人次门槛 100 → 7,000；`rank` 4 → 50）。

## 一、这一批解决什么

两件事，都是「量级」与「人味」：

1. **段位费贵了一个数量级**。原表 `CAPITAL.gradeFeeYuan` 合计 ¥333,000，按一碗 ¥10 算等于 **33,300 碗**；开罗是 8,330 碗。也就是说玩家为了升到顶，要卖掉相当于开罗四倍的粉。而三年总营收只有 ¥541,000 —— 段位费把整条资本线都堵住了。
2. **升段只有一句「评定通过」**。开罗 `grade_review` 十一级全是费用与门槛，评语是死字；我们连死字都没有。玩家花掉一大笔钱，屏幕上只弹一行系统消息。

## 二、只降费，门槛一位不动

新表（`game/src/data/anchors.ts` 的 `CAPITAL.gradeFeeYuan`）：

```
500 · 1,000 · 1,800 · 2,800 · 4,500 · 7,000 · 10,000 · 14,000 · 18,000 · 23,000 · 0
```

合计 **¥82,600 ≈ 8,260 碗**，与开罗的 8,330 碗几乎同量级。

`minCustomers` 保持 110 / 350 / 1,000 / 1,500 / 2,000 / 2,400 / 3,000 / 3,400 / 4,000 / 5,000 / 6,000 —— **这一批只碰钱**，因为门槛本来就和开罗同量级（开罗 100 → 7,000）。有测试锁住这十一行不许动。

## 六、替身四种子（与批次三同一份代码对新旧费率）

| 种子 | 月均营收 | 日均碗 | 流失 | 热卖 | 期末现金 |
|---|---|---|---|---|---|
| 1 | ¥134,823 | 194.1 | 52% | 317 | ¥192,680 |

| 3 | ¥115,170 | 113.9 | 75% | 11 | ¥94,084 |

| **均值** | **¥125,147 / 146.4 碗 / 66.3%** | | | | |

对比批次三（¥89,106 / 136.6 碗 / 68.5%）：**月均 +40%、期末现金三倍**。原因很直白：原来那 ¥333,000 段位费是替身最大的一笔现金去处，降下来以后钱能进设备与街面。

**这是预期内的，也是一个新的风险**：段位费从「刹车」变成了「过路费」（见缺口 P173）。

## 七、与开罗逐项

| 开罗 `grade_review` | 本作 |
|---|---|
| 11 级 | 11 级（同名量级：摆摊仔 → 非遗传承人） |
| 费用 5,000 → 5,000,000，合计 8,330 碗 | 500 → 23,000 元，合计 8,260 碗 |
| 人次门槛 100 → 7,000 | 110 → 6,000（本来同量级，不动） |
| 评语是一列死字 | 评语写进界面 + 评委当场再说一句（AI 第 15 落点） |
| `rank` 4 → 50 联动 | 本作段位与「手艺树」联动（`UNLOCKS` 10 条），未改 |

## 八、新缺口

- **P173** 段位费降下来后**失去了刹车作用**：替身期末现金从 ¥88k 涨到 ¥402k（种子 4），后期钱没去处。下一批（批 5 配料品质档 / 批 6 技法树）要靠「贵的正确玩法」把这笔钱重新吸走，而不是靠涨价。
- **P174** 评语十一句是通用的，不看**玩家这一碗强在哪**（味道 78 的和味道 52 的听到同一句「这口汤有底子」）。九档四维已经有读数，评语应该按最亮的那一维挑。
- **P175** `grade_voice` 的 key 只给段位数字，模型不知道玩家强在哪，容易说空话；本地四句也一样。
