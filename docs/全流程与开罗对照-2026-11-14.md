# 全流程与开罗对照 · 2026-11-14

> 起因：试玩反馈三条（m03752）——①「一进入游戏就是正在营业了，应该是从零开始的」；
> ②「教程没有和游戏进程独立，没有下一条、也没有关闭」；③「参考开罗，把全流程重新梳理」。
> 本文记录取证、改法、实测，以及和开罗拉面店的一一对照。

---

## 一、三句结论

1. **开罗没有「手动开关店」这个按键**——它的一天是自动循环的，但它有 Game Flow 1：
   先做出一碗能卖的，才有得卖。我们要的「从零开始」实质是**先备料、再开门**，不是加个开关店界面。
2. 本项目改成 **三态状态机 `prep → open → closing`**：新局停在 `prep`（时钟不走、没人来），
   玩家按顶栏「● 开门营业」才进入 `open`，到 14:00 打烊进 `closing` 出**日结单**，点「明天继续」回次日 `prep`。
3. 教程从「4 步挂在营业中」改成 **5 步绑阶段**（prep 四步 + open 一步），并补齐「下一步 / 先关掉（可恢复）/ 不用教了」。

## 三、状态机与代码落点

```
prep ──openShop()──▶ open ──(minuteOfDay 到 120)──▶ closing ──ackDayReport()──▶ 次日 prep
  ▲                                                    │
  └──────────── 事件弹窗 / 日结单未确认时，一律停表 ──────┘
```

| 文件 | 改动 |
| --- | --- |
| `game/src/sim/state.ts` | 新增 `type Phase = "prep" \| "open" \| "closing"`、`interface DayRecord`、`phase / dayReport / days`；`SAVE_VERSION` 6→7；导出 `openShop()` / `ackDayReport()` / `tickMinute()`；私有 `recordDay()` 打烊时把当天钉成一张日结单（营业额 / 碗数 / 走了几位 / 平均满意 / 现价 / 味道 / 现金） |
| `game/src/sim/shop-hours.ts` | 钟面换算：`SHOP_START_HOUR=6`、`CLOCK_MINUTES_PER_GAME_MINUTE=4`、`clockOf()`、`minutesLeft()`；一天 120 游戏分钟 = **06:00–14:00** |
| `game/src/sim/customer.ts` | `settle()` 累加 `satSumToday / satCountToday`（日结单要「平均满意」） |
| `game/src/sim/save.ts` | 接受 v5/v6/v7；v6→v7 迁移把 phase 归 `prep`、清当天计数 |
| `game/src/ui/hud.ts` | 顶栏加钟面 `[data-clock]`；`<div class="pill">` 换成可点 `<button class="pill prep">`；新增日结弹层 `.dayreport` 与「明天继续」；`onOpenShop / onNextDay` 两个回调 |
| `game/src/ui/hud.css` | `button.pill.prep/.live/.done` + 呼吸动画、`.clock.closed`、日结单整套样式 |
| `game/src/ui/guide.ts` | 重写为 v2（键 `laoyou.guide.v2`，兼容 v1）：5 步绑阶段、三个按钮、收起后可恢复 |
| `game/src/main.ts` | `onMinute()` 换成 `if (!tickMinute(state)) return;`；接线开门 / 明天继续 |
| `game/src/sim/dayflow.test.ts` | 新增 9 例守门（新局不走时间、重复开门无效、打烊停表、月末进下月、事件期间不动、`advanceMinute` 旧语义保留…） |

**一个刻意的取舍**：`advanceMinute()` 保留原语义（不判 phase），玩家侧只走 `tickMinute()`。
这样 131 个既有用例和三套 probe（`probe:rent` / `probe:flow` / `probe:win` / `probe:standin`）
不用改一行，玩家路径却又被管住了。

## 六、这一轮抓出的三个真 bug

| bug | 症状 | 根因 | 修法 |
| --- | --- | --- | --- |
| 日结单永远不出现 | `expected 'prep' to be 'closing'` | `advanceMinute()` 末尾那句 `state.phase = "prep"` 把 `recordDay()` 刚设的 `closing` 覆盖了，玩家永远等不到确认 | 删掉那行，由 `recordDay()` 独占 `closing`，`ackDayReport()` 负责回 `prep` |
| 顶栏按钮点不动 | Playwright 报 `<canvas> intercepts pointer events` | `#hud` 整体 `pointer-events:none`，只有 `#tray/#bottombar/.modal` 接事件；`.pill` 和 `.audio` 漏了 `pointer-events:auto` | 两处补 `pointer-events:auto`（顺带修掉「音乐」按钮一直点不动的老 bug） |
| 顶栏日期与日结单差一天 | 顶栏写 1 月 2 日、日结单写 1 月 1 日 | `endDay()` 先换日再渲染 | 有 `dayReport` 时顶栏按日结单的月/日显示 |
