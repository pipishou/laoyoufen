# 前端现代像素化（12 色板 · 像素字体 · 图标图集 · P57 · P58）

> 一句话：把三百多处随手写的十六进制颜色收成 **12 个色相**，给数字换成等宽、给界面配一套 24×24 的像素图标，再把「店里现在有几个人」和「这一招打出去是什么动作」两件玩家一直看不到的事画出来。

## 一、为什么做这一层

M1–M4 加的是**玩法内容**（同条街、街面、家当、人情、落场、AI 语声）。玩法越厚，界面越需要用同一种视觉语言把它们收在一起，否则玩家看到的是「一堆功能拼在一张纸上」。

这层的三条规矩，来自这个项目一路上的教训：

1. **颜色只能有一个真源。** 之前每个面板各自写 `#2f2118`、`#8b3a2f`、`#e9dcc3`，改一次主色要改十几处，还改不干净。现在 12 个 token 全部声明在 `game/src/ui/hud.css:3-25`，组件里一律 `var(--ink)`。
2. **像素风靠硬边，不靠圆角。** 所有描边 2px、阴影是**实心偏移**（`2px 2px 0`）而不是模糊阴影；切角用四角盖小方块（`.pixel-cut`），不用 `border-radius`。
3. **动效只在子元素上做。** 落场里那个小人的外层 `transform` 每一帧都被 JS 覆盖（它要横向走到对应的分数位置），所以动作帧必须画在内层 `<i class="fig">` 上 —— 这是这一步最容易做错的地方。

## 二、12 色板

| token | 值 | 用在哪 |
|---|---|---|
| `--ink` | `#2f2118` | 正文、描边、深底 |
| `--ink2` | `#5a4632` | 次要文字、对手色 |
| `--wood` | `#8a6f52` | 说明文字、木色摆设 |
| `--sand` | `#c9b28f` | 擂台地台、分隔 |
| `--cream` | `#e8dcc4` | 空位、进度条底 |
| `--paper2` | `#fff8e6` | 面板亮底 |
| `--paper` | `#fffdf6` | 卡片底、按钮底 |
| `--red` | `#b5493a` | 我、后厨、熟客 |
| `--orange` | `#d97b52` | 热卖、火气 |
| `--green` | `#2f7d4f` | 选中、在架、店员 |
| `--gold` | `#b8912f` | 座位、钱、客人 |
| `--blue` | `#4a6f8a` | 墙面、客流、街面 |

收口是脚本做的，不是手改：`tools/pixelize.py` 把 `game/src/ui/*.css` 里的 `#hex` 按加权 RGB 最近邻（绿色权重 0.6，因为人眼对绿最敏感、最容易看出偏色）映射到 12 个 token，然后整块重写 `:root` —— 旧变量名（`--shadow` `--brick` `--bamboo` `--mustard` `--sky` `--chili` `--sour`）保留成别名指到新 token，这样三百多处 `var(--brick)` 不用动。

**结果**：`game/src/ui/*.css` 里剩下的字面色值**只有 12 色板本身各一处**，全在 `hud.css` 的 `:root`。跑法：

```
python tools/pixelize.py            # 干跑，只打印映射
python tools/pixelize.py --write    # 落盘
```

坑：脚本第一版给每个 css 文件都插了一遍 `:root`，于是 `hud.css` / `hud.responsive.css` / `pixel.css` 出现三份真值，还有重复注释。用一个正则 `(/\* 12 色板.*?\*/\s*)+:root\s*\{.*?\}` 清掉后按文件补回：`hud.css` 插完整 12 色，`pixel.css` 只留 `--px / --stroke / --font-num`。

## 三、像素字体与数字

`game/src/ui/pixel.css` 里声明 `@font-face "Laoyou Pixel"`：

```css
src:
  local("Fusion Pixel 12px Proportional SC"),
  local("Fusion Pixel 12px Monospaced SC"),
  url("/fonts/fusion-pixel-12px-proportional-sc.woff2") format("woff2");
```

**有就吃，没有就安静回落** —— 不引外部 CDN，离线也能玩。想换成像素字，把字体文件丢到 `game/public/fonts/` 即可，不用改代码（当前仓库还没随包带字体文件，所以线上跑的是系统字）。

数字一律 `--font-num` + `font-variant-numeric: tabular-nums`：钱、评分、倒计时、冷却、单价都用这套，**读数不跳**（等宽数字的宽度一致，8 变成 1 时整行不会抖）。

## 四、图标图集

`game/src/ui/icons.ts` 里 12 枚 24×24 图标，用 `rect` 拼出来（像素图不适合用 path 曲线）：

`bowl` `coin` `star` `heart` `people` `grade` `street` `pan` `clock` `flag` `pot` `cup`

- `mountIcons()` 把 `<svg id="icon-sprite">` 插进 `body` —— **不能插进 `#hud`**，因为 `mountHud()` 会重写 `#hud` 的 `innerHTML`，图集会跟着被抹掉（引导条当年就是这么消失的）。
- `icon(name)` 返回 `<svg class="ic"><use href="#ic-bowl"/></svg>`，`fill: currentColor`，`shape-rendering: crispEdges`。
- `main.ts` 启动时 `applyPalette()` + `mountIcons()` 各一次。

真实使用点：**产能条的五枚胶囊**（`hud.ts` 的 `caprow`）——

> 👥 座位 4 · 2.0 分/碗 ｜ 🍜 日上限 200 碗 ｜ 🏮 客流 130/日 ｜ ❤ 人情 0 ｜ 🚩 比赛 5 个月后

以前是一长串文字挤在一行里，现在扫一眼能读出来。`.chip` 沿用 `hud.css` 里已有的像素描边胶囊样式（`pixel.css` 那套细边胶囊改名 `.pchip` 让位，避免互相覆盖）。

## 五、P57：把客人与店员画进店内小图

`game/src/sim/shopmap.ts` 在 `shopGrid()`（家当摆位）上叠一层「人」：

- `MapMark = GearSpot | "cust" | "staff"`，输出 12×8 = 96 格；
- **客人**从门口（右下 (11,7)）往左、往上排，最多画 12 个 —— 再多就看排队条，不用小图数人头；
- **员工**按角色分班位：掌勺（`role === "cook"`）占后厨四列，跑堂从后厨剩余位往后站；今天休息的人不画；
- 只在空格上落人，**不顶掉家当**（家当格子的含义比人重要）；
- 全程确定性、不消耗随机数 —— 同一份存档画出来一模一样。

标题那句话也接上了：`店里 · 摆了 6/12 件家当 · 排队 5 人 · 店里 2 人帮忙`，图例从 5 项扩到 7 项（多出「客人」「店员」）。

样式上客人与店员画成「一个脑袋 + 一个身子」（`::before` 8×6 头带帽檐、`::after` 6×6 身），色分别用 `--gold` 与 `--green`，不是一块死色。

## 六、P58：落场三招的动作帧

难点：`.arunner` 的 `transform` 每帧被 JS 写成 `translateX(...)`（小人要横向走到分数对应的位置），CSS 动画如果也写 `transform` 会互相覆盖。

改法：把视觉从外层挪进内层。

```html
<span class="arunner me" data-arunnerme aria-label="我"><i class="fig"></i></span>
```

- `.arunner`：只管定位、尺寸、`transition: transform`；
- `.fig`：只管样子与动作（底色、内阴影、`@keyframes astep` 上下踏步）。

出招时 `strike()` 调 `playAct(cmdId, gained)`：

| 招 | class | 动作 |
|---|---|---|
| 支摊吆喝 | `act-holler` | 跳两下，`scale(1.05, .95)` 压一下 |
| 端碗露一手 | `act-show` | 侧身 `rotate(-10deg)` 往前递 |
| 一锅端 | `act-pot` | 先蹲 `scale(1.15,.8)` 再弹 `scale(.9,1.25)` |

单招打到 **≥20 分**，对面加 `knock`：后退 6px + `brightness(1.7) saturate(0)` 白闪一下。

两个细节：

1. 连按同一招也要**从第一帧重播** —— `void el.offsetWidth` 强制一次回流，浏览器才会重启动画；
2. 动作 460ms 后由 `setTimeout` 摘掉 class，回到常驻的踏步动画（`ACT_MS` 与 `arena.css` 的 keyframes 时长对齐）。

## 八、缺口

- **P64**：像素字体文件没随包 —— 线上跑的是系统字，`@font-face` 只是留了接口。要真像素字就得把 woff2 放进 `game/public/fonts/`（中文全量约 2–3 MB）。
- **P65**：图标图集只用在产能条一处，面板标题、页签、按钮还是纯文字。
- **P66**：店内小图是静态的 —— 客人不会往柜台走、店员不会动；落场有动作帧，店里没有。
