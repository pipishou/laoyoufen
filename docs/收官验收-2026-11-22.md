## 五、CCGS 游戏性验收

1. **核心循环咬得住吗**：能。开门 → 炒 → 卖 → 打烊看单 → 第二天改一件事，一条线；批 12 的抽签前置让「改一件事」的后果可复现（热卖 cv 从 0.56 到 0.028）。
2. **有没有「钱没处花」**：这一轮从 ¥773k 压到队尾还有余（P203），但已上四条出口（燃气水 / 设备维护 / 零售采购 / 进货档），后期靠内容而不是靠惩罚。
3. **本土化是否成立**：八款货、三处物产、十二条笔记、四圈地名、十一句评委话，**每条都带出处**；三处物产只落单一出口（料钱 / 饮料 / 耐心），不叠乘。
4. **AI 是否只在合适处说话**：18 个落点，线上 **18 / 18 remote**；模型只说人话，数字一律本地算。
5. **像素 UI 是否守规矩**：字面色值 0 处、12 个 CSS 变量、`steps()` 硬切帧 7 处、`prefers-reduced-motion` 1 处；面板 42 段。
