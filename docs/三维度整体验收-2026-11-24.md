## 二、本土化：每一条都得出自本地

纪律沿用前几轮：**查不到南宁（广西）出处的东西，不进表**。这轮被这条纪律砍掉或改名的有：

- 杂货铺原本要写「打包饭盒 / 电蚊香 / 遮雨棚」三件，找不到能引原文的本地出处，**没有进表**（文件头写明了原因，防止以后凭印象加回来）。留下的是豆奶（Tripadvisor 复记点评「配上油条和豆奶就更完美了」）、绿豆沙（知乎南宁美食帖）、门口多亮一盏灯（新华网转广西日报「每晚十时…摊位便会准时亮灯」）、门口铺两张矮凳（解放日报「常有人端着碗蹲在墙边哧溜」）。
- 门路八条全部落在南宁的时间与空间上：夜市亮灯、中央厨房送一批、上文旅线路（「老友游南宁」「老友味道」）、产业学院展销、直播一场、请老师傅、跟料商多留一筐、请美食号写一篇。
- 二十四张地名是「熟面孔」而不是新行政区：中山路夜市、淡村市场、建政路、新阳路、农院路夜市、蒲庙老镇、武鸣城区、横州花市、宾阳圩日、隆安县城、上林河边、马山县城……每个区挂两处，地图上写的就是这些名字。
- 八十三条街面事件里，环境压迫型的（停水、气价、青菜涨、垃圾清运）**允许没有免费选项**，但纪律改成「每条都留一条花钱买口碑的路，绝不出现怎么选都掉口碑」。
- 手艺点树的二次确认里撤掉了「汤料位 +1」——`Recipe.soup` 是定长元组，全仓 `soupSlot` 命中 0，这个改法在本作里没有落点，换成「人情日上限 +2/级」。

开罗那边的对照点：`topping.txt` 44 条、`topping_combo.txt` 38 条、`fixevent.txt` 500 条、`talk.txt` 244 条、`mapchip.txt` 218 条。我们没打算在数量上追平，追的是「一句一处境」的密度——每次点开面板，同一段文字不该连着看第二遍。

## 三、AI 能力：口子收在同一处

这一轮把在线台词的账算清了：

- **总额**：`LINE_BUDGET` 260 → **320**。上一次统计是「49 个调用点、18 个 kind，键是名词，成本上限等于键空间」。加了店员成长、手艺、门路三处之后键空间约 275，320 是留了余量之后的天花板。
- **分项**：`LINE_QUOTA = { guest_talk: 40 }`。客型×场面这一项在长局里会吃掉一半预算（P243），单独划配额，超了静默走本地句。
- **新三处**（落点 22 → **25**）：
  - `staff_grow_voice`：店员长进时报一句，只在 `state.staff.lastEvent` 变化时说，不刷屏。
  - `perk_voice`：点下手艺时一句街坊话，`audit_ai` 实测「老友，这镬气爆得透，隔着几条巷子都闻见香了。」
  - `item_voice`：买门路/买杂货时一句，实测「多留这筐料在街上，汤头一滚就知有没有那份心。」
- **红线没松**：服务端 `LINE_RULES` 的 `CN_QUANTITY`（带数量词的整句直接丢）、不许报价钱、不许报回本天数、不许提段位榜单。上下文只给名词（`{事, 在哪}`），所以模型没法把数字编回去。
- **离线兜底**：每个 kind 都有本地句池，网络断了、预算用完了、服务端 400 了，界面上的字不会空着。

线上实测：`tools/gate/audit_ai.py` **25 / 25 remote**，全部走真服务，没有一条落回本地池。

## 四、前端现代像素风：三条硬要求都对着尺子量过

| 要求 | 实测 | 判据 |
| --- | --- | --- |
| 只用 12 色板 | 字面色值 **0**；`:root` 12 个 token（ink/ink2/wood/sand/cream/paper2/paper/red/orange/green/gold/blue） | 违规即红 |
| 只用 24×24 像素图标 | `IconName` **21** 条（这轮补了 bean 绿豆沙 / tea 凉茶 / lamp 灯 / chalk 价牌 / pencil 铅笔） | 新图标必须走 `icon()` |
| 动效走硬切帧 | `steps(` **8** 处、`@keyframes` **14** 条、`prefers-reduced-motion` **2** 处 | 有动效就必须有关闭 |

另外三个数字：`sechd` 段数 **57**、`icon(` 调用 **52**、`data-act` 种类 **44**。面板现在是七个页签（配方 / 员工 / 店铺 / 比赛 / 图鉴 / 账本 / 手艺），页签条改成横向可滚（`.mtabs{overflow-x:auto}`），窄屏也不会挤成一坨。

顺手补的两处：杂货铺每行的货名前面挂了自己的图标（豆奶是杯、绿豆沙是豆、风扇是钟、油条是锅），改名输入框前面挂了一支铅笔——这些都不是新花样，是把「这行是什么」在扫一眼的时候就说清。
