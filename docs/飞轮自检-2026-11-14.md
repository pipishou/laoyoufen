# 飞轮自检：玩家的试玩到底记不记得住（2026-11-14）

一句话：**v1 记不住，v2 记住了**。v1 的埋点在真实浏览器里一行都没落盘 —— 玩家关掉页面就全丢，而验收报告当时写着「每分钟埋点」是绿的，因为测试只测了内存。

## 一、怎么查的

用 Playwright 起真浏览器（msedge，1440×900），走玩家路径：清空 localStorage → 载入 → 关掉引导 → 切 ×16 → 让它自己跑 → 刷新 → 再刷新 → 按 `Shift+E` 导出。脚本 `tools/reviewer/` 之外，临时脚本跑完即删；结论全部来自浏览器里读到的真实值。

## 二、v1 实测（查出来的三个错）

| 现象 | 实测值 | 应该是 |
|---|---|---|
| localStorage 里有埋点吗 | **没有** `laoyou.telemetry.v1` 这个键（只有 `laoyou.save.v4` 与 `laoyou.guide.v1`） | 每 N 分钟落一次盘 |
| 刷新后还在吗 | **样本从 122 掉到 1** | 保留 |
| 累计卖碗 | **3,708 碗 / 122 分钟** | ≈ 130 碗 |

三个错，都是同一类：**「写了不少代码」被当成了「在记录」**。

1. `flushTelemetry()` 只在月结调用一次 —— 玩家一局要跑 100 多个游戏日，中间任何刷新/关页都归零。
2. `summarize()` 把「今日累计」当「每分钟增量」相加 —— 一天 120 分钟就翻 120 倍（122 分钟算出 3,708 碗）。
3. 环形 4,000 条 ≈ 33 游戏天，而一局 36 月 = 129,600 分钟 —— 就算落盘了，也只能留住最后一个月。

## 三、v2 的改法

- **日聚合**：把每分钟的样本折进当天的 `DayRollup`（一天 1 条，36 月共 1,080 条），全程留得住；
- **分钟细节环**缩到最近 600 分钟，只够看「刚刚发生了什么」；
- **落盘**：每 5 次采样、每次跨天、以及 `beforeunload` / `pagehide` / 切后台时都写一次；
- **数字对账**：当日累计量单调（`Math.max`），流失原因按「流失人数增量」记账 —— 否则一句粘住的「看价牌走了」会被数几百次；
- **导出**：`Shift+E` 直接下载 `playtest-YYYYMMDD.json`（也可控制台 `__laoyou.export()`）。

## 四、v2 实测

| 项 | 实测 |
|---|---|
| localStorage 键 | `laoyou.telemetry.v2`，**83,387 字节** |
| 32 秒 ×16 速度 | 492 游戏分钟 / 5 天 / 270 碗 / 流失 85 / 流失率 23% |

| console error | 0 |

## 五、飞轮五个环节，哪几齿咬上了

| 环节 | 状态 | 说明 |
|---|---|---|
| ① 采集（玩家侧） | ✅ 已通 | v2 埋点，日聚合 + 分钟细节 |
| ② 存储 | ✅ 已通 | localStorage，随时落盘；跨会话累积 |
| ③ 导出 | ✅ 已通 | `Shift+E` → `playtest-*.json` |
| ④ 读入并出报告 | ✅ 已通（本轮新建） | `tools/reviewer/playtest_ingest.py` → `docs/试玩记录-<日期>.md` |
| ⑤ 影响决策（棘轮） | 🟡 半通 | 报告会给出「顶到产能 / 降价螺旋 / 持平段」判读，但还没有自动写进账本与判据版本 |
| ⑥ 事件文案审核飞轮（另一条线） | ✅ 已通 | L0 规则 → L1 五判据 → k≥3 多数票 → 人审回填 |

没接的那一段我不含糊：**现在这份试玩数据不会自动变成决策**，它只是变成一份我看着能读懂、能拿来写决策卡的报告。要真闭环，下一步得让报告里的判读触发账本行 —— 那是 P25。

## 六、怎么用

1. 玩完（或玩到一半想让我看看）按 **`Shift+E`**，浏览器会下载 `playtest-YYYYMMDD.json`；
2. 把它丢进 `game/data/playtest/`；
3. 我跑 `python tools/reviewer/playtest_ingest.py`，出 `docs/试玩记录-<日期>.md`；
4. 报告里的「日均碗数 / 均价 / 流失原因 / 最长持平段」就是决策卡的证据。

>`playtest-20261114.json` 里那份是我用脚本替身跑出来的样例，用来证明管线通；**你自己的那份才有价值** —— 替身不会觉得无聊。
