# 批次 4.5 · 同行两款菜单与比价（2026-11-22）

## 一、这一批解决什么

开罗的同行店（`enemy_store` 115 行 / 25 家）每家有一份菜单，玩家能看见对面卖什么、卖几多钱。
我们此前每家只有**一款**招牌价，于是「比价」退化成一条直线：

> 只要我比那条街上唯一的那个数贵，客流就掉；唯一的对策是把价压到成本线以下。

压价压到最后，菜单系统、材料分级、配料品质这些**为了「做好」而存在的东西全部失效** ——
因为便宜能补一切。这就是账本里的 **P153**（同行有价目后比价单向压迫，会催生无脑降价）。

这一批两件事一起做：

1. 八家同行各加**第二款**：一贵一便宜（引流款 + 主力款），价格差 2–3 元 —— 真实粉店都是这么定价的；
2. 比价改成看**这条街的中间价**（两家两款的平均），并给「味道压得住」留一条免死金牌。

## 三、为什么比「中间价」不比「最低价」

第一版按开罗直觉做成「看这家的最便宜那碗」。跑替身立刻出事：

- 替身卖 ¥12，三姐的素粉 ¥6 把「最低价」压到 6，gap = +6；
- `PRICE_WAR_CAP = 0.12`，于是**每一家都吃满 −12%**，`priceWarMult` 恒在下限；
- 四种子均值 ¥118,420 / 131.7 碗 / 流失 70.5%，比上一批（¥125,147 / 146.4 / 66.3%）营收 −5.4%、碗数 −10%。

诊断一句话：**拿自家一碗老友粉去比人家六块钱的素粉，本来就不公道**。
街坊心里的「这条街一碗粉几多钱」取的是中位，不是最低那款 —— 一份素粉是配菜，不是对标物。

改成中间价（`cheapestOf` 现在返回两款的平均，函数名保留但注释改清楚了）：

- 三姐中间价 ¥7、老甘 ¥10.5、南湖 ¥13、凤岭 ¥14……；
- 我卖 ¥12 时，贵的只有南湖、凤岭两家，gap +2 / +1，各摊 −12% 的一部分，合计不远超上限；
- 我卖 ¥10 时，只比三姐贵 ¥3。

## 四、味道压得住，价牌不算数

`shieldedBy(myTaste, rivalBestTaste)`：我的味道比他最好的那款高 **10 分**以上，这家抢客力度打到 1/4。

这条是这一批真正的**反压价装置**：想让价牌失效，就把粉做好。
替身味道 72、段 11，压不住南湖（78），所以替身仍受比价影响 —— 数据上是真代价，不是白给。

## 五、接在哪

- `game/src/sim/price-war.ts`：`PRICE_WAR_CAP = 0.12`、`TASTE_SHIELD = 10`、`rivalPrices`（只列本区、未关门、未接手的，按 gap 降序）、`priceWarMult`（每家 `gap*0.02*weight / rows.length` 求和，夹 `[0.88, 1.06]`）、`priceWarWords`、`priceWarContext`；
- `game/src/sim/customer.ts` 的 `spawnChance` 在 `marketAttractMult(state)` 之后乘 `priceWarMult(state)`；
- `game/src/ui/panels.ts`：同行行加「菜单：猪杂粉 ¥9 ／ 牛腩粉 ¥12」，同条街段加比价那一句（`data-pricewar`）。

**第五次撞面板缓存键**：`panels.ts:1585` 的 shop key 里没有菜单价，改价后比价那句不动（探针实测卡在旧价 ¥9）。
补 `|${s.menu.map((m) => \`${m.id}:${m.price}\`).join(",")}|${(s.rivals ?? []).filter((r) => r.closed).length}` 才好。
规矩再记一次：**面板里出现的任何 state 字段都必须进缓存键**。

但比「最低价」版好：营收 +4.8%、碗数 +6.2%、流失 −2.7pt，且被素粉那种引流款牵着走的荒谬场景消失了。

## 八、与开罗逐项

| 开罗 | 本作 |
|---|---|
| `enemy_store` 115 行 / 25 家，每家一份菜单 | 8 家，每家两款（招牌 + 第二款） |
| 同行菜单是静态资产，不比价 | 每日本区比价，进店乘数 −12%…+6% |
| 味道与价格是两条独立轴 | 味道高 10 分以上 → 这家价牌失效（1/4 权重） |
| 玩家只能看，不能回应 | 改价、改菜单、提味道三条路都通 |

## 九、新缺口

- **P176** 同行价永不浮动：真实街头会互相跟价（你降我也降），现在八家的价是常量，只有我一方在动。
- **P177** 比价不看份量与配料：¥8 的小碗和 ¥12 的大碗按同一个数比，缺「每碗多少肉」这一维。
- **P178** 免死金牌只有一个阈值：10 分是拍的，没验过 8 分 / 12 分对策略的影响。
- **P179** 第二款只出现在面板文字里，没有「他家今天推哪款」的动态。
