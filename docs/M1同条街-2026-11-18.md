# M1 同条街 —— 让门前这条街真的有人跟你抢（2026-11-18）

## 0. 三句话

1. **这一批做的不是「加一个面板」，是把「客流池」从常量变成对手的函数**：本区潜客 × (1 − 同行份额) × (1 + 接手加成)，于是「这条街有几家店」直接决定你一天能卖多少碗。
2. **同行的份额会自己长大**（每月名气 +1），也会被压下去（口碑 ≥3 时 −2、≥4 再 −1），撑不住就关门；关门后的铺子可以**接手**——租金打七折，门口多一个入口。
3. **比赛第一次有了街坊意义**：赢一场会让本区最强的那家「记一笔」，赢到 3 次它服气，抢的人砍半；服气的邻居每月还送一次食材。量尺（替身）实测：月均 ¥59,930 → **¥69,553**，成长 ×2.46 → **×3.34**，T3 持平从 12 个月缩到 **6 个月**。

## 3. 四个接线点（都在既有乘数入口，没有新引擎）

```ts
// ① 客流池：game/src/sim/district.ts —— demandCapOf()
const street = (1 - rivalShareOf(state)) * (1 + takeoverPoolBoostOf(state));
return Math.max(8, Math.round(base * homeEnergyOf(state) * roadworkBoostOf(state) * street));

// ② 房租：game/src/sim/setup.ts —— monthlyRentOf()
return Math.round(rentMonthlyOf(base, state.month) * takeoverRentFactor(state));

// ③ 月初结算：game/src/sim/ledger.ts —— closeMonth()
const street = rivalMonthTick(state);          // 名气 +1 / 被压 / 关门 / 换台词
const giftYuan = Math.round(pacifyGiftOf(state) * 30 * BOWL.costYuan);  // 服气的邻居送食材
state.cash += giftYuan;
if (street.lines.length > 0) state.flow.lastStreet = street.lines.join("；");

// ④ 比赛：game/src/sim/contest.ts —— 赢了前三名
const top = strongestRival(state);
if (top && noteWin(state, top.def.id)) {
  state.flow.lastStreet = `${top.def.name}服气了：门口挂块「输给你」的牌，抢的客砍半`;
}
```

份额公式（`game/src/sim/rivals.ts`）：

```ts
export function shareOfOne(rs: RivalState): number {
  if (rs.closed) return 0;
  const base = Math.min(SHARE_CAP, rs.fame / 120);   // SHARE_CAP = 0.35
  return rs.pacified ? base * 0.5 : base;            // 服气 → 砍半
}
```

## 7. 缺口

- **P49**：同行只有 8 家、只覆盖 4 个区；青秀/西乡塘的 tier3 缺一家，「这一带有名的老店」压制感不足。
- **P50**：AI 街坊传闻没接（本地模板轮换 3 条/家，玩 12 个月就会听全）。
- 接手后「门口多一个入口」只体现在池子 +10%，没有视觉表现（像素门面留 M1b 的 48×48 像素头像）。
- 比赛仍与「12 个外地城市样本」比分数，只有赢的**后果**接到了同条街；对手本体没进赛场。
