# 真实物价与设备 S4（2026-11-15）

## 一、三句结论

1. **尺子换了**：这一轮把「钱」的第一性来源从「开罗 KCU × 0.01」改成**南宁 2025 年的真实观测值**——一碗老友粉卖 10 元、料钱 4.8 元、社区店房租 4,600 元/月、最低工资 2,200 元/月。开罗的 KCU 只用来定「比例关系」，不再用来定绝对数。
2. **一碗的成本从 4.2 元改到 4.8 元**，毛利 5.8 → 5.2 元（毛利率 58% → 52%）。这不是手感调整，是按六项拆账对出来的：粉 0.6＋猪杂 1.2＋配料 0.9＋汤底 0.7＋能耗 0.8＋损耗 0.6。
3. **S4 设备上线**：三件主线设备（猛火灶 / 粉篓与汤勺 / 案台与备料区）各四档 ¥1,500 / 3,800 / 9,000 / 30,000，真点验收通过——买一台灶出碗从 6.0 分降到 5.1 分，买一张案台日上限从 200 碗抬到 240 碗。

## 二、真实物价取证（全部写进 `game/src/data/anchors.ts` 的 `SOURCES`）

| 项 | 观测值 | 来源 |
| --- | --- | --- |
| 广西最低工资（2025-07-01 起） | 一类区 2,200 元/月、22.4 元/小时（调整前 1,990 / 20.1） | 广西政府政策解读、新华广西 |
| 老友粉定价 | 老友猪杂粉 / 碎肉粉 10 元，牛肉粉 12 元；人均客单 12–15 元 | 老南街传统老友粉店价目 |
| 一碗净利 | 3–4 元（店家口径） | 同上 |
| 猪肉（南宁淡村农贸市场 2025-10） | 五花 12、梅头 11、前后腿 10、排骨 20 元/斤 | 南宁晚报（光明网转载） |
| 铺面 | 良庆 58 ㎡ 临街粉店 7,600 元/月；青秀/兴宁临街 30 ㎡ 年租 10.6 万；社区店比临街便宜 3–5 成 | 房产平台在租房源 |

> 「一碗净利 3–4 元」和「卖 10 元、料钱 4.8 元 → 毛利 5.2 元」不矛盾：店家那 3–4 元是**扣完房租水电人工之后**的净利，我们游戏里的 5.2 元是**只扣料钱**的毛利，房租和工资在月结里扣。

## 三、坐标系（`game/src/data/anchors.ts`，唯一换算点）

| 组 | 内容 |
| --- | --- |
| `BOWL_BREAKDOWN` | 粉 0.6 / 猪杂 1.2 / 配料 0.9 / 汤底 0.7 / 能耗 0.8 / 损耗 0.6 = **4.8** |
| `BOWL` | `priceYuan` 10、`beefPriceYuan` 12、`avgTicketYuan` 15、`costYuan` 4.8、`marginYuan` 5.2 |
| `TIME` | 36 个月 × 30 天 × 120 游戏分钟；1 游戏分钟 = 6 现实分钟 |
| `LABOR` | 最低工资 2,200 元/月、22.4 元/小时；帮工 3,800 元/月；师傅 4,500 元/月 |
| `RENT` | 街边摊 1,500 / 社区店 4,600 / 临街 7,600 元/月 |
| `CAPITAL` | 风格套 3,000–8,000；设备 1,500 / 3,800 / 9,000 / 30,000；扩建 12,000 / 35,000；区县转让费上限 120,000；段位费合计 333,000 |

三把尺子（给玩家看的换算）：

- `bowls(yuan)`：¥21,000 月营收 = 2,100 碗；
- `monthsOf(yuan)`：¥12 万 ≈ 5.7 个月营收（一间区县店的转让费）；
- `laborHours(yuan)`：¥3,000 的设备 = 一个最低工资工人 134 小时的工资。

## 四、S4 设备（`data/equipment.ts` + `sim/equipment.ts`）

| 设备 | 现实原型 | 效果 | 四档价格 |
| --- | --- | --- | --- |
| 猛火灶 | 商用双环猛火灶 | 出碗时间 × 0.85/档（6.0 → 5.1 → 4.3 → 3.7 → 3.1 分/碗） | ¥1,500 / 3,800 / 9,000 / 30,000 |
| 粉篓与汤勺 | 漏勺与定量汤勺 | 食材成本 × 0.97/档（一碗省 0.14 → 0.56 元） | 同上 |
| 案台与备料区 | 切配台 + 备料冷柜 | 日上限 +40 碗/档（200 → 240 → 280 → 320 → 360） | 同上 |

为什么只留三件：开罗 `storeequip.txt` 有 24 件，其中真正影响「一碗粉怎么更快更省」的只有火力、煮制、案面三类；饮水机、雕像、净化器属于氛围件，归 S3 布置做 charm，不进产能链。

接线点：
- `sim/customer.ts`：`const cost = score.cost * costMultiplier(state) * equipCostMultiplier(state);`、`flow.serveCooldown = FLOW.serveMinutes * serveMultiplier(state) * equipServeMultiplier(state);`
- `ui/panels.ts`：店铺页签新增「设备 · 现在出碗 X 分/碗」段，三行各带实时价格与效果说明；
- `ui/hud.ts`：产能行改成实时 `出餐 X.X 分/碗`；
- `sim/state.ts`：`equipment: Record<string, number>`，`SAVE_VERSION` 8 → 9（v8 老档补空对象）。

## 六、与开罗对照

| 维度 | 开罗 | 本作 | 结论 |
| --- | --- | --- | --- |
| 设备件数 | 24 件，价格 5–10,000 KCU | 3 件 × 4 档，¥1,500–30,000 | 件数少但每件都改变产能/成本，开罗那 24 件大半是氛围 |
| 设备价格锚 | 顶档 8,000 KCU ≈ 80 元（按 0.01 折算） | 顶档 ¥30,000 ≈ 3,000 碗 ≈ 一个半月毛利 | 开罗的资本价在本作完全不能用，必须按月营收重定 |
| 效果可见性 | 数值面板 | HUD 产能行 + 面板标题实时刷新 | 本作更直观 |
| 拉开差距的机制 | 技能树（45 条） | 设备四档 + 段位费 + 解锁树（P3 待做） | 机制数量还差一档，靠 P3 补 |

## 七、已知缺口

1. **S2 招人 / S5 扩建 / S3 布置 / S6 分店** 都还没做（本轮只做 S4）。
2. S5 扩建仍走旧的 `UPGRADES`（¥1,500 一次），和新坐标系 `CAPITAL.expansionYuan = [12,000, 35,000]` 不一致，等 S5 落地时统一。
3. 设备不看「店铺风格」：开罗里不同风格的设备外观不同，本作还没做外观层（S3）。
4. `sim/grade.ts` 的段位评定仍无 UI 入口（B6 △），钱赚到也花不出去。
5. 味道仍不直接换钱（P22）：本次只把「成本」这一侧接上了现实，售价与味道的耦合还要单独做。
