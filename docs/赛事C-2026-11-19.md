# 赛事 C 批：14 场具名赛事（五级阶梯）

日期：2026-11-19 · 提交：`feat(c): 14 场具名赛事…` · 线上：http://8.134.86.249/laoyoufen/

## 三句话

1. 开罗 `rally.txt` 54 行全是「换名字 + 抬门槛」，**没有一场有主办方、没有一句开场白**（`First Arena → Royal Bowl 2` 一共 18 个场子名）。
2. 我们做了 **14 场具名赛事、分五级**：街道办 → 城区 → 南宁市 → 广西 → 全国，每场都有**真会办这种事的单位**当主办，报名费与对手分**一律引用已有的 `CONTEST_TIERS`，一个新数字都没造**。
3. 开场白接 AI 第 7 个落点 `tourney_open`：街道办像邻里活动、夜市像吆喝、非遗中心像正式评审 —— 同一个「比赛开始」在不同主办嘴里完全是三件事。

## 为什么是这五级

用户口径：「南宁街道办-城区级-南宁市级-广西级-全国级，这几个应该够了」。落地时按 **现实中一家粉店真能往上走的路径**排：

| 级 | 谁办 | 一年几次 | 我们的处理 |
|---|---|---|---|
| 街道办级 | 街道办 / 夜市管委会 / 社区居委会 | 随时 | `when: "anytime"`，一天一场 |
| 城区级 | 区文化馆 / 区商务局 / 区文广体旅局 | 六月 | `when: "june"`，一届一场 |
| 南宁市级 | 市人社局 / 市商务局 / 南宁日报 | 十二月 | `when: "december"`，需城区进过前三 |
| 广西级 | 自治区商务厅 / 广西烹协 / 自治区文旅厅 | 十二月 | 需市级进过前三 |
| 全国级 | 中国烹饪协会 / 非遗保护中心 | 十二月 | 需广西进过前三 |

刻意**不做「世界大赛」**：老友粉是南宁的东西，做到全国已经是这条线该有的天花板。开罗那套 `World Championship / True World Champ` 放到这里就是脱节。

## 三条设计纪律

1. **层级照现实，不照开罗。** 开罗 `World Champ Ticket / True World Champ / Royal Bowl` 是它的世界观；南宁这条线到全国为止。
2. **主办方写真的会办这种事的单位。** 「街道办」和「非遗中心」的口吻差得远，这正是 AI 落点能立住的地方；写成「竞技场」「大赛组委会」就白瞎了。
3. **费用与对手分一律引用 `CONTEST_TIERS`，不新造。** 14 场全部映射到 `tier 1–5`（`feeYuan` 0/300/800/2000/5000，`prizeYuan` 1,200/3,000/8,000/20,000/50,000，`rivalScore` 70/130/210/310/430），这样「月赛」与「具名赛」的强度是同一把尺子。

## 三个接线点

**① 把「评分 + 名次 + 副作用」抽出来共用**（`game/src/sim/contest.ts`）

```ts
export function runBoardCore(
  state: GameState,
  type: ContestTypeId,
  tier: number,
  roundKey: string,
): BoardOutcome   // { score, rank, prize, champion }
```

`enterContest`（每月两次的月赛）与 `enterTourney`（具名赛）都走它，注释写明「两个入口出成绩的口径必须一模一样」。副作用（口碑 +0.35/+0.2/+0.06、人情 `contestTop3`、`contest.wins`、最强同行 `noteWin`）只在这里写一次。

**② 六道门槛写成一处**（`game/src/sim/tourneys.ts`）

```ts
export function tourneyGate(state, def): { ok: boolean; reason?: string }
```

依次判：局已结束 → 月份不符 → `anytime` 当天已打（`state.tourneyDay === month*100+day`）→ `june|december` 当届已报（`state.tourneyRound === contestRoundOf(month)`）→ 前置（`needLevel` + `needRank`，要「上一级任一场进过前三」而不是「打完上一级」）→ 段位与报名费。

**③ 报名就是一条动作**（`game/src/sim/tourneys.ts`）

```ts
export function enterTourney(state, id): TourneyResult | null
// 扣费 → runBoardCore(...) → 加奖金 → tourneys[id] = { played+1, best: min }
// → anytime 记 tourneyDay，其余记 tourneyRound
```

面板（`panels.ts` 的 `contestHtml`）把 14 场按五级折成 `.tgroup`，每场一行：名字 + 成绩 + `主办｜比什么｜报名 · 冠军 · 需第 N 段`，报不了的按钮直接 `disabled` 并在行里写原因（「今天已经打过一场了，明天再来」「这场只在每年十二月办」「要先在街道办级进过 3 名」）。

## AI：第 7 个落点 `tourney_open`

- 本地池 6 句（「各组准备，先看汤，再看粉。」「今天来的人多，灶别慌，手别抖。」…），先上屏，再异步换成 AI 的。
- 上下文只递名词：`{ 场: 场次名, 主办: 主办单位 }`，不递段位、不递对手分。
- 服务端 `LINE_SCENES["tourney_open"]` 的指令是「看主办是谁调整口气：街道办像邻里活动，非遗中心像正式评审，夜市管委会像吆喝」。
- 数字红线三层过滤照旧（阿拉伯数字 / 中文数量词 / 机制词），任一命中整句作废、回落本地句。

## 与开罗逐项对照

| 项 | 开罗 `rally.txt` | 我们 |
|---|---|---|
| 场次 | 54 行（18 个场子名 × 多种难度） | 14 场 |
| 主办方 | **无** | 14 个，每个都写真实单位 |
| 开场白 | **无** | AI 第 7 落点 + 本地 6 句 |
| 门槛 | 列 5–8，3 → 27 递增 | 引用 `CONTEST_TIERS` 的 `minGrade` 0/2/4/6/8 |
| 奖金 | 1,000 → 24,000 | 1,200 → 50,000（与月赛同一把尺子） |
| 层数 | 世界大赛 | 全国封顶（老友粉出不了这个圈） |
| 晋级 | 打赢上一级 | 在上一级**进过前三**（`needLevel` + `needRank`） |

## 缺口（记进账本）

- **P80** 街道办级 `tier 1` 对手分只有 70，成熟店稳拿冠军 —— 等于**每月白拿 ¥1,200**（替身日志里几乎每月一次）。要么加「卫冕难度递增」，要么让街道办级只发人情不发钱。
- **P81** 赛事没有「连续参赛 / 卫冕 / 恩怨」叙事，全靠 AI 一句开场白撑场子。
- **P82** 全国级两场是「招牌 + 后厨」，**没有街坊口碑的**；广西级三场都有，全国级缺一条。
- **P83** 赛事成绩只进 `tourneys[id].best` 与成就 `contest_top`，图鉴页看不到「拿过哪些名次」。
