# A10 南宁轻地图 · 2026-11-21

## 一句话

开罗 `mapchip.txt` 218 行是逐格贴图。我们不做可走地图 —— 一局两分钟，玩家不会去逛。这张图只回答三件事：**我在哪个区、哪些区有我的分店、还有谁在这条街上抢客**。

## 怎么摆的

十二个区按真实相对方位摆进 6×4 的格子，上北下南：

```
马山        武鸣        上林
  西乡塘                  宾阳
隆安      兴宁 良庆 青秀 横州
   江南        邕宁
```

只用 `MAP_SPOTS` 一张手写坐标表，不引地图图片、不引第三方库 —— 像素格就是地图。

三条纪律：

1. **地图是视图，不是状态**：不新增任何存档字段，只读 `state.district` / `state.branches` / `state.rivals`。
2. **一格只说一件事**：名字 + 同行数字 + 「在这 / 分店」标。多一个字都不放。
3. **同行只落在当前区**：`RivalState` 没有区字段，八家都在你所在的区 —— 硬画到别的区就是编数据。
