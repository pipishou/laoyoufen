# A → B → C 三批实施（2026-11-18）

按 `docs/下一步动作建议-2026-11-18.md` 的推荐顺序做完了三批，四道门全过，已上线。

## 一、一句话

把「前 30 分钟」修好（A），把「像不像成品」补上（B），把「两套系统各玩各的」缝起来（C）——
新玩家第一天的流失从 53% 降到 **24%**，第一段段位从第 6 个游戏日提前到 **第 2 天**。

## 二、A：首屏 30 分钟

三件改动，都只动开局，不动中后期。

### A1 客流按天分档（`game/src/sim/customer.ts`）

```ts
export function spawnScaleByDay(state: GameState): number {
  if (state.month !== 0) return 1;
  if (state.day <= 1) return 0.55;
  if (state.day <= 7) return 0.85;
  return 1;
}
```

`spawnChance()` 里 `FLOW.spawnScale * spawnScaleByDay(state)`。

**为什么不是「前 3 天 ×0.55」**：替身 36 个月实测，那样做月均从 ¥78,485 掉到 ¥62,385、
热卖从 138 次掉到 12 次 —— 开局少的那点现金流掐断了热卖正反馈，后面 30 个月追不回来。
只压首日、2–7 日轻压，替身不退化。

### A2 前两级段位门槛（`game/src/sim/grade.ts`）

`GRADES[0].minCustomers` 400 → **110**，`GRADES[1].minCustomers` 700 → **350**，第三级起不动。
原来第一段要 400 位客人 ≈ 第 6 个游戏日，玩家前 30 分钟摸不到任何段位奖励。

### A3 打烊单给一个「明天」（`game/src/sim/hook.ts`）

`nextHookOf(state)` 五级优先级，越具体越好：

1. 差客 ≤80 →「明天再来 N 位客人，就能评「X」」
2. 人次够、差钱 →「明天把钱凑到 ¥N」
3. 能评 →「明天去评「X」，交 ¥N」
4. 第一件买得起的家当 →「明天添一件「X」（¥N）」
5. 买得起的街面 →「明天修「X」」
6. 能落场 →「明天再去落一场（X）」
7. 全满 → 不显示

渲染在日结单 `.dayhook`（左侧 3px 金色竖条 +「明天 · 」前缀）。**sim 层不 import UI 的 `money()`**，
自己写了个 `yuan()`，避免依赖倒挂。

## 三、B：门面收尾

### B1 像素字体随包（P64）

- 来源：`TakWolf/fusion-pixel-font` 2026.11.10 的 `12px-proportional-otf.woff2` 包（4.9 MB），
  取 `zh_hans` 子集 → `game/src/ui/fonts/fusion-pixel-12px-proportional-sc.woff2`，**694,824 B**。
- 下载路径：`api.github.com` 与 `raw.githubusercontent.com` 在本机都不通，最后走
  `https://gh-proxy.com/https://github.com/...`；npm 上的 `@fontsource/fusion-pixel-12px-proportional-sc@5.3.0` **只有 latin 子集**，没有中文。
- 关键：`@font-face` 的 URL **必须是相对路径** `./fonts/…`。`vite.config.ts` 是 `base: "./"`，
  线上挂在 `/laoyoufen/` 子路径，写 `/fonts/` 会 404。
- `body` 字体栈改成 `"Laoyou Pixel", "SimSun", "宋体", monospace`，`font-display: swap` 安静回落。

### B2 图标铺开（P65）

- 图集从 12 枚扩到 **16 枚**（新增 `staff` / `shop` / `book` / `crate`）。
- 六个页签用 `icon(name)`（**24px = 1:1**）；30 处面板段标题用同一枚图（14px）。
- **坑**：18px 显示 24×24 的 rect 图是非整数倍，2px 的缝被挤成 1px 再被吞掉，页签变成一排黑方块；
  段标题 12px 同样糊，改成 14px + `shape-rendering: auto`（交给矢量平滑）才认得出。
  像素图必须 1:1 或干脆当矢量用，别夹在中间。
- 旧的内联 16×16 字符画图集 `ICONS` 删掉，一套图集一个真源。

### B3 店内小图会动（P66）

```css
@keyframes smbob { 0%,100%{transform:translateY(0)} 50%{transform:translateY(-1px)} }
.shopmap .sm-cust::after  { animation: smbob .9s steps(2,end) infinite }
.shopmap .sm-staff::after { animation: smbob 1.3s steps(2,end) infinite }
```

客人动得比店员快半拍，一眼看出店里有人在忙；`prefers-reduced-motion` 下关掉。

## 四、C：系统咬合（P60）

落场赢了**当场**压同条街最强那家：

```ts
if (win) {
  const target = arenaRivalEntryOf(state);
  const rs = target ? (state.rivals ?? []).find((r) => r.id === target.id) : null;
  if (target && rs) {
    const justPacified = noteWin(state, target.id);
    rs.fame = Math.max(0, rs.fame - 1);
    rs.lastLine = justPacified ? `${target.name}服气了：「做不过你，客人都往你那边跑。」` : …;
    if (justPacified) line += `；${target.name}服气了，往后少抢你一半的客`;
  }
}
```

**不做第二套计数器**：落场赢、比赛前三名都走 `noteWin`，赢满 3 次就服气（份额砍半），
名气归零则月底关门。玩家只需要记住一条规则。
