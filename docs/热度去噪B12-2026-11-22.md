# 批次十二（前半）：热度去噪——先掷骰子，再判队满

> 依据 `docs/下一轮开发方案二-2026-11-22.md` 批 12。这一批原定三件事：抽签前置、热卖结算去噪、现金四出口。
> 前两件做完并实测；第三件（现金）没做，理由见 §五，不装作做完了。

## 一、解决什么

四种子替身跑出来的营收差三成（¥89,106 / ¥96,818 两组的对照里，单种子 −26%），
我们一直以为是「行情压坏了经济」。批次三查过一次，结论是 rng 流错位；这一批把它修到底。

真正的问题在 `arriveOne` 的**第一行**：

```ts
const waiting = flow.customers.reduce(...);
if (waiting >= queueMaxOf(state)) { lostQueue += 1; return; }   // 旧：队满直接走人
const regularId = maybePickRegular(state);                       // 到这里才开始掷骰子
```

被队满挡在门外的那位客人**不消耗随机数**。于是任何让客流动一点点的改动
（行情 ±2%、买一张凳子、评一个段位）都会改变「谁被挡住」，
整条 rng 流从那一刻起错位，热卖点火/熄火、36 个月全变。

这就是 P171 说的「以为在调经济，其实在掷骰子」。

## 二、抽签前置

`game/src/sim/customer.ts` 的 `arriveOne` 改成「先掷四颗骰子，再判队满」：

```ts
const regularId = maybePickRegular(state);
const archRoll = nextFloat(state.rng);
const tierRoll = nextFloat(state.rng);
const dishRoll = nextFloat(state.rng);

const waiting = flow.customers.reduce(...);
if (waiting >= queueMaxOf(state)) { lostQueue += 1; return; }   // 骰子已经抽掉了
```

「来一个人」固定抽 4 次（常客 + 原型 + 档位 + 挑款），
无论他最后坐下、看价牌走，还是被挡在门外。

**测试**：`src/sim/customer.test.ts` 新增一例，用计数代理数「一次队满的分钟里 `rng.s` 被碰了几下」——
只抽进店那一颗是 2 下，加上被挡住那位的 4 颗必然 ≥ 10 下。
不用「两局跑到最后 rng 相等」来测：结账时挑边菜（`sides.ts`）与事件本身就按经营结果消耗随机数，
那个等式从一开始就不成立（这条也是这次踩出来的）。

## 三、攒槽规则：排队从「门槛」降为「加成」

`game/src/sim/frenzy.ts` 原判据：

```ts
const satisfying = waiting >= FRENZY_MIN_QUEUE && goodBowls >= 1;
```

排队是**前提**，于是小店的命运被写成二值的：座位多、队伍不积的店一天都没在攒槽，
另一个种子天天攒。四种子实测热卖 344 / 234 / 19 / 332 次，标准差/均值 **0.56**。

改成按满意度攒槽（这才是开罗原句 `customers are eating ramen that they like`），
排队留着，但变成**加成**：

```ts
const gain = Math.min(
  FRENZY_MAX_GAIN,
  FRENZY_PER_BOWL * Math.max(1, goodBowls) * (waiting >= FRENZY_MIN_QUEUE ? 1.5 : 1),
);
const satisfying = goodBowls >= 1;
```

一句话：**热卖是客人高兴的结果，不是有人站着的结果。**

## 五、现金出口：这一批没做，理由与下一步

方案里写的判据是「期末现金 ¥80k–¥200k」，实测 **¥388k–¥817k**，差得远。没做的原因是：
真正能吃掉这笔钱的不是参数，是**还没做的内容**（批 7 零售线要买设备与货、批 10 店内格子要买家具槽位、
批 9 地图要买分店）。先加一个「月度维护费」把数字压下去，等于用一个假成本掩盖内容缺口。

下一步（已写进账本 P200）：

1. **燃气与水**：粉店是真烧气的，按出碗数计 ¥0.30/碗 进每碗成本（不是月底一刀切）；
2. **设备维护**：每台每档 ¥90/月 × (1 + 0.12 × 段位)，满配段 11 约 ¥3,340/月；
3. **续约涨租**：租金随段位涨（生意好了房东就涨，这是南宁铺面的常识）；
4. 三条合计预估吸收 ¥250k–¥350k，剩下的缺口交给批 7–10 的采购。

  测试只能锁顺序契约（见 §二）。
