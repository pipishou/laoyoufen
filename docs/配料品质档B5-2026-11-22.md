# 批次 5 · 配料品质档（2026-11-22）

## 一、这一批解决什么

开罗没有「进货档次」这一层：它的配料（`topping` 37 行）是固定值，四维写死在表里。
我们前几批把「配料组合」「味道层」「材料分级（米与骨）」都做了，但**同一份浇头永远只有一种货**——
玩家多花的钱只能花在设备、门面、店面这些大件上，**每碗里没有可调的东西**。

南宁粉店每天真在做的判断却是这个：同样的猪杂，档口送来的和自己清早去挑的，不是一个东西；
酸笋新坛和陈坛，出来的味也不一样。这一批把这件事做成**一档开关**。

## 二、出处（三条，全部核过原文）

| 出处 | 原文 | 用来支撑什么 |
|---|---|---|
| 新华网《南宁老友粉：人因此味「粉」邕州》 | 「老友粉的灵魂在于酸笋、豆豉、辣椒酱、蒜米四味主料」；老师傅谢胡春盯着坛中酸笋叮嘱徒弟：「如果酸笋发酵过久，酸度超标，会盖过豆豉的醇厚。」 | 酸笋有发酵的度，**过老的坛子会盖味** —— 所以「贵一档」不是「多一档」 |
| 百度百科《南宁老友粉》 | 「所用酸笋、酸辣椒、豆豉等原料都必须用传统的腌制方法腌制」 | 原料本身分得出好坏 |
| 蜗食记《南宁老友粉》 | 「粉肠需后放以保持脆嫩」「炒干酸笋水分」 | 头手货的差别在处理与新鲜度上，不是玄学 |

## 三、三档

| 档 | 名字 | 跟档口怎么说 | 相（charm）抬高 | 料钱乘数 |
|---|---|---|---|---|
| `plain` | 平常货 | 档口送什么就用什么 | 0 | ×1 |
| `good` | 靓货 | 清早自己去挑，不将就 | +25% | ×1.8 |
| `top` | 头手货 | 托熟人留的那一份 | +55% | ×2.6 |

**三条纪律**（写在 `game/src/data/quality.ts` 文件头）：

1. 只落在已有的两个出口：**相（charm）**与**料钱**。不开新维度 —— 开了就要重跑全部回归锁；
2. 默认档两个乘数是 0 与 1，所以历史分数一分不动；
3. 没有「又便宜又好吃」的一档 —— 每上一档料钱都贵得多。

**为什么不收一次性的钱**：这一档不是「买一件东西」，是**每一碗都在多花的料钱**。
钱从 `costMult` 走，看得见地在每碗毛利里；再收一次钱就是重复收费。

## 四、接在哪

- `game/src/data/quality.ts`：三档表 + 出处 + `qualityById`（坏 id 退 `plain`）；
- `game/src/sim/quality.ts`：`qualityOf` / `setQuality`（免费切，认表内）/ `qualityCharmBoost` / `qualityCostMult` / `qualityViews` / `qualitySummary` / `qualityWords`；
- `game/src/sim/score.ts`：
  - `ScoreExtra` 加 `quality?: string`，memo key 拼进档位（**不然换档分数不重算**）；
  - `charm` 改成 `30 + (charmBase - 30) * (1 + charmBoost)` —— 只抬 30 以上的那一部分，
    因为 30 是「一碗粉该有的样子」的地板，地板不因为进货贵就变高；
  - `cost` 只乘配料那一段：`BASE_COST + topCost * costMult + 主料 + 分量 + 米骨`。
    **不乘整碗**，否则「头手货」会把主料与分量也变贵，说不清。
- `game/src/sim/menu.ts`（`scoreDish` 传 `state.quality`）、`game/src/sim/dish.ts`（`scoreOf` 同上）、
  `game/src/sim/state.ts`（两处 `scoreRecipe` 直调也补上）；
- `game/src/sim/state.ts`：`SAVE_VERSION 31 → 32`、`GameState.quality: string`；
- `game/src/sim/save.ts`：判废白名单加 `31`，迁移 v31→v32（坏值退 `plain`）；
- `game/src/ui/panels.ts`：配方页 `.econ2` 之后加 `.qbox`（抬头「进货 · 平常货 · 料钱照旧」+ 三枚 chip），
  `qualityKey` 变化才刷（含现金千位，避免买完东西不刷新）；`PanelActions.setQuality` + `case "quality"`；
- `game/src/main.ts`：`setQuality` action（toast 用档位自己的那句话）；
- `game/src/ui/hud.css`：`.qbox/.qhd/.qlist/.qb` 像素小签（用已有 12 token）。

## 七、与开罗逐项

| 开罗 | 本作 |
|---|---|
| `topping` 37 行，属性写死 | 37 件浇头 + 三档进货（每档改「相」与料钱） |
| 没有进货概念 | 有，且免费切换、按碗计费 |
| 品质靠「升级配料」提升 | 我们不上「同一件配料升级」，改**整批进货档次** —— 更接近真实采买 |
| — | 味道（total）完全不受档次影响：进货只换卖相与成本 |

## 八、新缺口

- **P180** 三档是整批的，做不到「酸笋买头手、猪杂用平常」的混搭（真实老板会这么干）。
- **P181** 档位没有时间成本：清早去挑本来就该占掉一点晨间时间。
- **P182** 「头手货」不掉货：托熟人留的那一份应当有概率拿不到。
- **P183** 相（charm）抬高的 25% / 55% 是拍的，没验过对菜单选择的影响。
- **P184** 进货档没进打烊单与街坊报，玩家换了档外面没人提。
