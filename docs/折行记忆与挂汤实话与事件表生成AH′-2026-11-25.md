## 一、开罗怎么放这四件事

| 开罗的做法（英文版资源原文） | 这里的做法 | 落在哪 |

## 二、P412：折行开合记住了

打烊单「为什么」那块在 375 宽只显示三条，第四条往后要点「还有 N 条 · 点开」。点了之后**关掉游戏再进来又收回去** —— 批 AD′ 留下的缺口。

- `game/src/ui/prefs.ts`：`Prefs` 加 `whyOpen: boolean`，`defaultPrefs()` 给 `false`，`normalizePrefs()` 只收布尔值。
  - 注释写清为什么不进存档：「这是这台机器上的习惯，换手机该重新点，也不该占 `SAVE_VERSION`」。
- `game/src/ui/hud.ts`：
  - `let prefs: Prefs = loadPrefs();` **上移到打烊单元素表之前**（原来声明在设置弹窗那段，模板里调读它的函数会撞 TDZ —— 批 AG′ 白屏就是栽在这上面，第二次不踩）；
  - `let whyOpen = prefs.whyOpen;`；
  - 折叠按钮的点击：`whyOpen = !whyOpen; prefs = { ...prefs, whyOpen }; savePrefs(prefs); foldWhyLines();`。
- 判据（`fold_probe.py`）：点开之后 `localStorage["laoyou.prefs.v1"]` 里 `whyOpen === true`；**刷新页面再塞一份日结**，不点任何东西就该是展开的（`fold_state_remembered`）。

## 三、P405：挂汤那句不再写死

原来 `speakThick()` 传的上下文是死字符串：

```ts
context: { 汤: "挂得住", 嘴: "黏" },
```

模型只知道「稠」，不知道垫底的是猪脚卤水，也不知道今天这碗多不多 —— 所以十二句里总会撞出同一句。

现在 `game/src/sim/soupbase.ts` 多一个 `thickContext(state)`：

| 键 | 怎么算 | 例 |
| --- | --- | --- |
| `底` | 固定「猪脚卤水」（当下只有猪脚底会记挂汤） | 猪脚卤水 |
| `汤` / `嘴` | 固定两个口感词 | 挂得住 / 黏 |
| `多` | 当天挂汤碗数 ÷ 出碗数：≥0.6 / ≥0.3 / 其余 | 大半碗都走的这条路 / 有几碗走这条路 / 只出了一两碗 |
| `味` | 当天口味分：≥70 / ≥45 / 其余 | 回头客说这口味正 / 客人吃得下 / 有人说口重了 |

**一个阿拉伯数字都不给**：服务端 `CN_QUANTITY` 红线会把带数量词的整句丢掉，给了数字等于把句子扔掉。

`game/src/sim/thick-context.test.ts` 五例盯着：垫底说得出、三档「多」、三档「味」、整块不匹配 `[0-9]`、没有打烊单也不吐 `undefined`。

## 五、P344：服务端事件表有了生成器

`server/app.py` 的 `deepseek_narrative()` 要用事件的 `title` / `body` 喂模型，读的是**服务端自己那份** `server/events.json`。游戏里的 `EVENTS` 涨到八十三件时那份副本还停在批 N′ 之前的三十二件 —— 线上 health 的 `"events": 32` 就是这么露的，当时用手写脚本补的。

- 新 `game/tools/server-events.gen.ts`：把 `EVENTS` 映射成 `{ id, source: "static_v1", title, body, weight, cooldownDays, choices[] }`，与磁盘上的 `../server/events.json` 比对，**一样就不写盘**（反复跑不会造出假 diff），不一样就整表重写。
- 新 `game/vitest.gen.config.ts`：只含 `tools/**/*.gen.ts`，`npm test` 的主套件不受影响。
- `package.json` 加 `"gen:server": "vitest run --config vitest.gen.config.ts"`。
- 第一次跑的结果：**八十三件，与游戏逐条一致，没有写盘** —— 说明上一轮手补的那份是对的，现在是生成器在保证它继续对。
- 坑：生成器放在 `src/` 下会被 `tsc` 盯上 `node:fs`（`TS2591`，本仓没装 `@types/node`）；挪到 `game/tools/` 之后就不在 `tsconfig` 的 `include` 里了。

## 七、新缺口

- **P418** 折行记忆存在本机 prefs 里，换设备就回到收起（可接受，但界面没说）。
- **P419** `thickContext` 的三档分界（0.6 / 0.3、70 / 45）是照现有分布拍的，没有对着成交数据校准。
- **P420** 生成器只对账「内容一致」，没有「游戏加了事件但忘了跑 `gen:server`」的告警 —— 部署脚本里没有这一步。
