## 五·八、批 AQ′ 新记的缺口

22. **P455** `DEMAND_TAG` 与 `hud.css` 的 `.daywhy [data-demand-line]::before{content:"卖不动 · "}` 是「同一份事实两处写」，CSS 读不进 JS，只能靠单测字符串匹配对齐 —— 改 CSS 写法（空格、引号）不会不一致，但会红。跨语言同源目前只有这一个土办法。
23. **P456** `data/demand.ts` 是第一个「只为文案而存在的数据模块」，`entry-counts` 43 项不覆盖它（它不是条目表）—— 文案类常量没有条数对账，与 P440 同型但方向相反。
24. **P457** 四条路里的「换个人多的区」只是文案：游戏里换区＝**重开一局**（换初始区），不是「搬店」。玩家照着做会发现与想象不一样。
