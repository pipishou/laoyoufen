# 批 G′：设置页——开罗七项设置里，我们做哪五项

> 依据：`TheRamenSensei/取证/textassets/xls_out/English.lproj__text.txt`（1173 行，设置项只出现七处）
> 对应缺口：P278–P281

## 一、开罗原文读出来的七项

把 `text.txt` 里出现过「设置」语义的行捞出来，只有这七条：

| 开罗设置项 | 原文/取值 | 本作有没有对应物 |
|---|---|---|
| 画质 | 高 / 中 / 低 | 没有。固定 2D 像素画面，画质档位没有可动的东西 |
| 性能 | 普通 / 高速 | 没有。时间轴是我们自己按游戏分钟推的，没有渲染负载档 |
| 音乐 | 开 / 关 | **有**，但原来只有一个「音乐」按钮同时管音乐与音效，关了就全哑 |
| 音效 | 开 / 关 | **有**，同上，不能只关一边 |
| 音量 | 一档滑条 | **有**（总线增益），但界面上摸不到 |
| 画面旋转 | 自动 / 固定 | 没有。竖屏横屏都按 CSS 自适应 |
| 中断续玩 | 开 / 关 | 有，而且常开：每回合自动存档（`laoyou.save.v4`） |

所以「照开罗的设置做」不是照抄七行，而是**把七行里我们真有的那五项补齐并分开**，
再加一项我们自己需要的（像素风在亮屏下的可读性）。

## 二、做了哪五项

1. **音乐**开/关 —— 循环 BGM 单独一个闸。玩家常在后期关掉，因为曲子是 8 小节循环。
2. **音效**开/关 —— 出碗、进账、门口那几声短音，与音乐分开。
3. **音量**三档（低 / 中 / 高）—— 对应 `VOLUME_GAIN = { low: 0.3, mid: 0.55, high: 0.85 }`。
   开罗是一档滑条；手机上滑条不好点，三档是同类问题的另一种解法。
4. **高对比** —— 换一套色板（`--ink #000000`、`--sand #6d5c43`、`--gold #7a5c08`…），不动版式。
5. **大字** —— 只放大「一眼要看」的那几个数字（顶栏 stat、浮层 k/v、时钟），不动整站字号。

存 `localStorage` 的 `laoyou.prefs.v1`，**不进存档、不占 `SAVE_VERSION`**（换设备就该重新选）。

## 四、两个真坑

1. **根节点色板是内联的**：`render/stage.ts` 按画面缩放把整套 `--ink … --blue` **写进 `document.documentElement.style`**。
   内联样式优先于任何样式表规则，所以 `html.prefs-contrast{--ink:#000}` 一个字都没生效（探针 `contrast_token_dark` 首跑就红在这）。
   改法：`applyContrastPalette()` 同样写内联，**开的时候先把原值存下来，关的时候还回去**。
2. **顶栏按钮点不动是老坑**：`#hud` 整体 `pointer-events:none`（让画布接句柄），只有顶栏/托盘/底栏单独放开。
   `.prefsbtn` 第一版没写 `pointer-events:auto`，Playwright 点 30 秒超时。
   另外 `.stat .v` 本来就是 15px，「大字」第一版也写 15px，等于没变（探针 `bigtext_bigger` 红）→ 改成 18px。

## 七、新缺口

- **P278** 音量只有三档，没有「音乐小、音效大」这种分路音量（开罗也只有一档，但我们是两条总线）。
- **P279** 高对比只换色板，没换字号/线宽；真正需要的人还要「大字」再点一次。
- **P280** 设置存在本机，**不写在存档里** —— 换了浏览器或清了缓存就回到默认，界面没提示这一点。
- **P281** 没有「恢复默认」按钮；改乱了只能手动清 `localStorage`。
