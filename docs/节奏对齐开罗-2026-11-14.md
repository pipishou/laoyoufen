# 节奏对齐开罗拉面店（2026-11-14）

> 用户口径（m04160）：节奏照搬开罗——建店 → 第一碗老友粉 → 逐渐招人 → 店面布置 → 扩建；
> 核心差异化只有三样：**本土化 / AI / 前端 UI（AI 重构的像素风比开罗更现代）**，其他内容都可以照搬。
> 取证：`D:\项目\REA\REA\逆向\_逆向上游\TheRamenSensei\取证\textassets\xls_out\English.lproj__*.txt`（39 张表）；
> 本项目现状取自 `game/src/**` 实测。数字凡属「换算」的均写明换算方式，凡属「[推定]」的不参与结论。

## 一、结论先说（三条）

1. **开罗的节奏不是日历，是「奖励表解锁 + 三道门」**。`rank.txt` 16 条奖励行每一行都是一个**新动词**（加形状 / 加汤料 / 加浇头 / 扩建大厅 / 修路 / 买店 / 加排队位 / 多投资），行内直接写着前置条件；`grade_review.txt` 11 级审查（费用 5,000 → 2,000,000）是**钱的主要去处**；`region.txt` 7 区（解锁费 0 → 30,000，人口 500 → 30,000）是**客流池**。三者咬合，玩家永远有明确的下一步。
   → 我们上一轮删掉月营收 KPI 是对的，但删完之后**没有补上驱动源**，于是替身实测 M03–M35 营收恒定 ¥27.2k、流失 0%、零决策（P24）。
2. **我们的资本价格梯度断了一整个数量级**。现有 6 件升级合计不到 ¥7,500（`game/src/data/shop.ts`: 加桌 900 / 加灶 2,400 / 扩建 1,500 / 招牌 700 / 空调 1,200 / 装饰 800），段位费 ¥50–¥20,000（`game/src/sim/grade.ts`），而月营收 ¥27k、三年攒下 ¥24.8 万现金。**开罗的梯度是 4 档 ×10 倍级差的设备 + 4 档店铺 + 11 级审查费**；我们是一档。
3. **节奏的骨架照搬开罗，皮肉全用广西物件**——六阶分别为：选铺建店 → 第一碗 → 招人 → 布置 → 设备 → 扩建 → 开分店（12 区县已有转移费 ¥0–¥12 万）。三样差异化各有分工：**本土化负责物件与文案，AI 负责每个节点的命名与叙述，UI 负责节点本身的可见性**。机制形状与开罗一致，玩家看到的全是南宁。

## 五、三批交付（每批带验收断言）

**P1 建店仪式（0.5 天，SAVE_VERSION 7→8）**
- 新局进 `phase: "setup"`：先选铺位（3 档，决定初始 seats/capacity/cash）、起店名（AI 生成 5 个南宁口吻候选 + 可改，走 `POST /event` 的同一套代理，失败回落本地模板）、点「开张」。
- 验收断言：新局首屏必须先出现铺位选择；未开张前 `openShop()` 返回 false；存档写盘后重载仍在 setup。

**P2 资本梯度 + 段位门（1.5 天）**
- `data/shop.ts` 升级扩成 3 类 × 4 档：灶/粉篓/案台（价格 1,500 / 3,800 / 9,000 / 30,000），旧的 6 件降为 S3 布置层的「小件」；`sim/grade.ts` 费率换成上表；UI 加「评定」入口（现在零调用，K-01）。
- 验收断言：`probe:standin` 36 月里现金不再单调上涨——期末现金与「升满级所需总额」同阶（±50%）；第 3 个月后至少出现一次「钱不够升下一档」的等待。

**P3 解锁树 + 布置风格（1.5 天）**
- 新 `data/unlocks.ts`：16 行，`{id, name, require:{grade?, customers?, dayBest?}, costYuan}`，与开罗 rank 表同形；「未解锁」在 UI 里显示为**带条件的灰项**（照搬开罗「看得见拿不到」）。
- 6 套风格 × 5 部件，只改 charm/进店率与像素外观，不改数值平衡。
- 验收断言：点击任一灰项能看到「还差什么」（数字），点已解锁项能直接买。

## 六、三样差异化的分工（明确边界，避免「照搬」变「换皮」）

| 层 | 负责什么 | 不负责什么 |
| --- | --- | --- |
| 本土化 | 每个解锁节点的**物件与文案**（铺位/风格套/岗位/区县/菜名） | 数值与门槛形状（那是开罗的） |
| AI | 店名候选、每阶解锁时的一句南宁口吻旁白、事件叙事（已有代理与缓存） | 数值、平衡、判定 |
| 前端 UI | 节点可见性：灰项 + 条件 + 差值提示；布置的即时预览；段位门的仪式感 | 玩法逻辑 |

## 七、双镜

- **镜子一（我自己的视角）**：K-01 `applyGrade()` 至今零 UI 调用，段位是「有层没门」；K-02 六件升级合计 <¥7,500 而月营收 ¥27k，玩家三期就能买空，之后 24 个月无事——这不是数值问题，是**没有下一档**；K-03 12 区县数据齐但 `tally.districts` 永远只有兴宁一个。
- **镜子二（替身/玩家视角）**：J-01 开局没有「这是你的店」的仪式，直接一间 4 座铺；J-02 钱涨到 20 万没有任何东西在等你买；J-03 「布置」在 UI 里只有两个滑不动的开关（招牌/装饰），玩家感受不到「我的店长什么样」。
