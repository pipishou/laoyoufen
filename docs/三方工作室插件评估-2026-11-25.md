# 三個「游戏工作室」移植版：值不值得装（2026-11-25）

> 问的是 HYClub/deepseek-harness-game-studios（DSGS）、vekina/dsh-game-studio、bullish0x/GameStudio 这三个「把 CCGS 搬到别家宿主」的仓库，值不值得装、对本作有什么帮助。
>
> 结论先给：**一个都别装成主力；挑三条机制抄过来就够，剩下的成本比收益高。** 下面每条都带证据。

## 二、它们能给我们什么（只留真的对应得上账的六条）

我们现在的门：`tsc` / `vitest`（96 文件 1011 用例）/ `copy_gate` / `eye_gate`（五视口 175 色 stamp）/ `ai_gate`（29 落点）/ 12 个专用探针 / 替身四种子 / `gen:server` 对账 / `autoplay_probe`（无头连跑 37 天）。**流程不是我们的短板**——缺口在 ACCEPTANCE 第五节：P429（AI 台词失败无冷却，真 bug）、P70（钩子先点产能还是座位）、P422/P425（经济判据）、P417（只改说法的批次没有不靠经济数字的锁）、P431–P435（界面细节）。

按「能不能补上这些账」筛，值得抄的只有：

1. **帧差回归（DSGS 的 `/grow` + `replay --as reference|copy|story`）**
   它把两版页面帧对帧比，`match yes/no` 是硬判据。我们只有 `eye_gate` 的**色数 stamp**（175 这种计数），挡不住「颜色数没变但整块挪了」。这一条能补 P417 的一半：只改说法的批次，用帧差证明「除了那段字，像素级没动」。
2. **长跑 soak（bullish0x `/soak-test` 的协议形状）**
   我们的 `autoplay_probe` 只记 fps 与 4xx，**从没量过 30 分钟后的堆增长**。真心跳加速、DOM 泄漏就在这条线上。协议本身是文字，抄起来零成本。
3. **存档篡改清单（bullish0x `/security-audit` 的判据项）**
   我们的 `save.ts` 有 v36→v37 的白名单清洗，但只测过 perk 脏值。清单里「localStorage 直改 / 字段类型翻转 / 超长字符串 / 负数字段 / 复制别人的档」这五路，我们一条都没进 `vitest`。
4. **flaky 记账（bullish0x `/test-flakiness`）**
   我们已经付过学费：`--no-file-parallelism` 不加就有 `customer.test.ts` / `events.test.ts` 假红。它给的是「按 CI 日志找不确定用例」的流程，落到我们就是一条规矩 + 一个文件，成本极低。
5. **debug 残留检查（DSGS 的 `/share`：dist 里还有调试面板就直接失败）**
   我们的线上包里 `window.__laoyou` 是**在的**（state / export / upload / flush）。单机游戏不算漏洞，但「发布包里允许有哪些调试出口」从来没被断言过，值得一条门。
6. **内容条数对账（bullish0x `/content-audit`：GDD 声明的条数 vs 实际实现）**
   我们有 83 事件 / 24 地名 / 16 手册 / 21 浇头 / 10 杂货 / 24 大赛，全靠 `audit_counts` 与单测数着。它给的是「文档声明 → 代码事实」双向比的口径，能顺手把 `count_entries.py` 升级成会红的那种。

## 三、不该借的四条（会和我们已有的资产打架）

- **`/prototype` 一条龙**（问 8 个问题 → 直接产可双击的浏览器游戏）：我们是**存量移植 + 数值调优**，不是从零起项目。它那套 `projects/<name>/config.js` 与我们 `game/src/**` + `dist/` 完全是两个世界。
- **工作室目录**（`design/` `docs/architecture/` `production/` `src/` `assets/`）：我们已经有 `docs/`（30+ 份批次文档）、`.junshi/ledger.md`（146 行正本）、`AGENTS.md`（开工协议）。谁再建一套「GDD / ADR / sprint」，两份真相立刻分叉——P344（服务端事件表走散）就是同一类问题的前科。
- **49 个角色卡当 subagent 用**：DSGS 自己在 Limits 里写明「DSH 无法给每个 agent 限定工具集」；bullish0x 的「问 → 给 2–4 个选项 → 你拍板」这套协作协议，我们已经在 `AGENTS.md` 与 `laoyoufen-batch` 技能里写了更贴本作的版本（三读、五门、数值纪律、八件交付物）。
- **slash command 依赖**：两边都提醒「不同宿主不一定暴露 slash command」。DSGS 的 `/start` 还是靠 `~/.dsh/skills/start` 这个用户级 bootstrap 撑起来的——装完是**全局**生效，不是「这个仓库生效」。

## 四、真要装，怎么装才不炸

- **DSGS 装在独立 profile 里**：`dsh plugin --profile gamestudio add https://github.com/HYClub/deepseek-harness-game-studios`，别用默认 profile。这样它那 19 个 profile 级 hooks 只在 `gamestudio` 下开火，我们 `laoyoufen` 的工作流不受影响；要试就 `dsh --profile gamestudio` 单独开个会话。
- **别让它接管 `AGENTS.md`**：本仓库 `AGENTS.md` 是开工协议（三读 / 技能路由 / 五门 / 数值纪律 / 八件交付物），是这台机器上唯一被系统自动注入的那份。GameStudio 的 `AGENTS.md` 进来只会和它抢。
- **只读引用优先**：vekina 那份连装都不用——`read skills/soak-test/SKILL.md` 就能按它做，卸载就是关掉文件。
- 卸载路径记下来：DSGS 是 `~/.dsh/dsgs` + `~/.dsh/skills/{dsgs-init,start}`；bullish0x 是它自己的 `manifest.tsv` 只删自己装的文件。

## 五、建议的下一步（三件小时级实验，都不装框架）

按「能补哪条账」排序，建议下一批（批 AL′）就做这三件：

1. **帧差回归**：新 `tools/gate/framediff_probe.py` —— 同一状态截两版，逐像素比，判据「只改说法的批次：差异像素必须全落在指定区域内，否则红」。补 P417。
2. **存档篡改五路**：`game/src/sim/save-tamper.test.ts` —— localStorage 直改 / 类型翻转 / 超长串 / 负数 / 跨档复制，五条都要么洗干净要么拒收。补 P429 之外的另一半「存档安全」账。
3. **长跑 soak**：给 `autoplay_probe.py` 加 `--minutes 20` 与堆采样（`performance.memory` 或 CDP heap），判据「20 分钟后堆增长 < 30% 且 fps 不破 45」。补「连跑几十天」这条线的记忆泄漏。

## 六、和我们上一轮已经借过的对照

上一轮读的是 ZSeven-W/dsh-game-studio（另一个仓库，0.1.0-rc.6），从它那里借的是**无人值守试玩的契约**（`window.__gameState()` / `window.__autoplay()`、每秒 10 次决策、报告形状 `phases/fps/errors/requests`），已经落成 `tools/gate/autoplay_probe.py`，实测 5 分钟走到第 37 天，并顺手逮到 P429。

**这三个仓库里没有第二个「契约级」的东西**——剩下能给的都是流程文本，而流程我们已经有了。所以：**机制继续抄，框架不装。**
