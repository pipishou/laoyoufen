# 门路位随段位长（批 BC′）

> 2026-11-27 · GAP 四轮第五节最后一批（B/C 系列的收尾）
> 上一批：BB′「买一段安稳」→ 本批补上「宽一点」→ 门路从第 1 天到第 900 天不再是一个宽度

## 一、这一批要解决什么

`docs/GAP四轮-2026-11-26.md` 第四节 D 条原话：

> 门路没有成长：投资位数量是常数 —— 开罗 `rank.txt` 有 `More Investments`『Invest in more things at once.』，随等级增长的是**同时能投几条**；本作 `data/invest.ts` 的约束是『同类同时只能一条』，投资位固定为 2，不随段位长；体感：门路系统从第 1 天到第 900 天是同一个宽度，后期只剩『换一条更贵的』。

开罗那边到底是什么？取证文件 `TheRamenSensei/取证/textassets/xls_out/English.lproj__rank.txt` 第 16 行：

```
16  More Investments  12  Invest in more things at once.  0 0 1 3 2 1 2
```

和第 2 行 `Max Thickness` 的尾巴 `0 0 1 3 24 1 1` 形状一样 —— 都是**只给一档**。也就是说开罗那条解锁只做一次「+1」；GAP 四轮要求把它摊成两处门槛（第五段、第八段各 +1），是本作自己的延伸（这一段也写进了 `invest3` / `invest4` 的注释）。

### 修之前这里有什么问题

1. **「同类只能走一条」是一条假约束**。它看着像设计，其实是 `make` / `voice` 两类各一条的巧合：只要同类买过一次，同类的另一条就永远写着「先等 X 过去」。
2. **批 BB′ 把这个巧合戳穿了**。加上第三类 `hedge` 之后，「两类各一条」正好等于「同时能挂两条」，于是位子数从 2 悄悄变成 3，而玩家看到的仍是「同类只能走一条」这句话 —— 说法和行为已经对不上。
3. **没有上限这回事**。既然按类互斥，就不存在「挂满了」；也就没有「撤一条」这条出路 —— 中途想换一条只能等它到期，看着像死局。

## 二、改法：位子是一个数，不再是类的规则

### `game/src/sim/invest.ts`

```ts
/** 开局就有几位（照开罗 `More Investments` 的第一档） */
export const INVEST_BASE_SLOTS = 2;

/** 能同时挂几条门路：底板两位，第五段三位、第八段四位 */
export function investSlots(state: GameState): number {
  let n = INVEST_BASE_SLOTS;
  if (isUnlocked(state, "invest3")) n += 1;
  if (isUnlocked(state, "invest4")) n += 1;
  return n;
}

export function investSlotsLeft(state: GameState): number {
  return Math.max(0, investSlots(state) - activeInvests(state).length);
}

/** 「2 / 3 位」——面板抬头那一句就是它 */
export function investSlotsWords(state: GameState): string {
  return `${activeInvests(state).length} / ${investSlots(state)} 位`;
}
```

`buyInvest` 的三处顺序很重要：

```ts
export function buyInvest(state: GameState, id: string): BuyResult {
  const def = investById(id);
  if (!def) return { ok: false, reason: "没有这条门路" };
  if (investToday(state, id)) return { ok: false, reason: "这一条已经在走了" };
  // 位子判在现金之前：先把「挂不下」说清楚，再谈钱够不够 ——
  // 反过来会出现「钱扣了没买上」这种最难查的账。
  const live = activeInvests(state);
  if (live.length >= investSlots(state)) {
    const first = live[0];
    return { ok: false, reason: first ? `先撤一条（现在「${first.name}」占着）` : "先撤一条" };
  }
  if (state.cash < def.costYuan) return { ok: false, reason: `还差 ${money(def.costYuan - state.cash)}` };
  state.cash -= def.costYuan;
  state.investments = { ...(state.investments ?? {}), [id]: dayIndexOf(state) + def.days };
  return { ok: true, line: def.line };
}
```

`cancelInvest` 是这一批唯一新增的写操作：

```ts
export function cancelInvest(state: GameState, id: string): BuyResult {
  const def = investById(id);
  if (!def) return { ok: false, reason: "没有这条门路" };
  if (!investToday(state, id)) return { ok: false, reason: "这一条本来就没在走" };
  // 不退钱：退钱就等于「花钱买位子、随时退」的免费租位，能被反复刷。
  const next = { ...(state.investments ?? {}) };
  delete next[id];
  state.investments = next;
  return { ok: true, line: `撤了「${def.name}」，位子空出来了（这钱不退）` };
}
```

三支 reason 现在是：

| 情况 | 面板上写 |
| --- | --- |
| 已经在走 | `在走 · 还剩 N 天` ＋「撤一条」按钮 |
| 位子挂满 | `先撤一条（现在「料商留货」占着）` |
| 钱不够 | `还差 ¥120` |

### `game/src/data/unlocks.ts`（10 条 → 12 条）

| id | 段 | 名字 | 效果 |
| --- | --- | --- | --- |
| `invest3` | 5 | 多认一条街的门路 | 门路位 2 → 3（同时能挂三条） |
| `invest4` | 8 | 门路再添一位 | 门路位 3 → 4（同时能挂四条） |

`invest3` 的注释里写明为什么这件事不能等：

> 批 BC′ 前这里是「同类只能走一条」，两类各一条正好等于同时两条 —— 于是「2 位」这个说法从来没在界面上出现过。批 BB′ 加了第三类 `hedge` 之后，那条规则会悄悄让玩家同时挂三条，而文案还写着「同类只能走一条」。这里把它换成真的位子数，2 从此是一个能被读到的数。

`invest4` 的注释记下了它的短期尴尬：

> 三类各挂一条 = 三条，第四位要等第四类门路才有用 —— 记 P504。仍然做，因为「第八段再宽一位」本身是玩家能感知的成长，而只给到三位会让第八段这一档在门路系统里空掉。

顺手改掉一条错标注：`legend`（第 11 段，效果是「所有区能量不再衰减」）的 `kairo` 原来写「More Investments（更多投资位）」—— 那是 `invest3/invest4` 的出处，不是它的。改成「无对应（本作自造）：开罗 17 行里没有「全区连锁」」。

## 五、没动什么

- **门路还是十条**（`INVEST_TOTAL` 10）：本批不加门路，只改「能同时挂几条」。
- **一个乘数都没加**：位子是数量约束，不加任何倍率（纪律一 / P154 不动）。
- **不退款是为了堵刷钱**：`cancelInvest` 只删条目、不退现金；`investUntil`、`hedgedMarketIds` 都按天算，撤掉之后对冲当场失效（这一点由 `bb_probe` 的 `undo_gives_inspection_back` 继续看着）。
- **替身策略一行没改**：`standin.probe.ts` 仍然完全不买门路，所以本批对四种子应当是恒等变换。

## 六、新记的缺口

| 编号 | 缺口 |
| --- | --- |
| **P504** | 第四位门路位要等「第四类门路」才有用：三类各挂一条 = 三条，第八段那一位短期用不满。仍然做（第八段需要有东西可给），但体感上这一段是空的 |
| **P505** | 「撤一条」只能撤自己已在走的，不能换位：想从 A 换成 B 得撤 A 再买 B，两次操作中间那一瞬是「位子空着」的状态，没有一步到位的「换」 |
| **P506** | 位子数只在门路抬头写了一次（`2 / 3 位`），街道总览 / 账本 / 打烊单里都没有它，玩家在别处看不到自己还有几位 |
| **P507** | `investSlots` 读的是 `isUnlocked("invest3"/"invest4")` 两条硬编码 id，加第三条位子解锁要改函数体（不像 `PARALLEL_BY_TIER` 那样由数据表驱动） |
| **P508** | `legend` 的 `kairo` 从「More Investments」改成「无对应」了，但 `unlocks.test.ts` 里那条 kairo 断言只查 `More Investments` 是否存在，不查它是否**对得上**（同型于 P497） |
